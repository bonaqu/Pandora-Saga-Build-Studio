## Сила навыков в Книге героя — 0.760.0
- Если в Skill Effects для **текущего доступного навыка** вычислен ровно один коэффициент силы по верифицированным OS-векторам, показывать его в главной строке (например, «Сила удара +20%») вместо большого «—» и повторного элемента ниже. Для нескольких эффектов сохранять один краткий список, не выводить крупный пустой результат.
- В единственном существующем «Подробнее» показывать ближайший следующий прирост +1 коэффициента от зелёного мастерства, а для подходящих стихийных заклинаний и от ИНТ. Порог пересчитывается по исходному целочисленному округлению; не выходить за предел профессии, не обещать следующий порог после замены умения улучшенной версией, не отображать пороги для недоступных навыков.
- Коэффициент навыка **не** есть окончательный урон по врагу и не изменяет постоянную АТК. Расчёты только читают актуальные игровые записи; не добавлять служебные предупреждения, панели, автоприменение или новые поля в билды. ## Подтверждённая двухсекундная модель и несовпадения OS-описаний — 0.750.0
- **Не утверждать, что «2 секунды» нигде не известны.** Remaked `js/calc.js`, блоки `LPsec`/ `MPsec`, буквально подписывает восстановление «каждые 2 секунды». OS Регенерация 310002001, Восстановление 310022001, Природное восстановление 330005001 используют `FV2=[0,0,0,2]`. В Книге героя показывать **ОЗ/ОМ каждые 2 сек.
