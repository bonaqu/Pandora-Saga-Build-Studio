# Pandora Saga | Build Studio

**Character Planner · RU / EN**

[Открыть Build Studio](https://bonaqu.github.io/Pandora-Saga-Build-Studio/) · [Текущий релиз](site-version.json) · [Изменения](CHANGELOG.md) · [Все старые релизы](docs/changelog/README.md)

Веб-планировщик персонажей Pandora Saga: происхождение и профессия, характеристики, мастерство, экипировка и души, Книга героя, Энциклопедия и библиотека билдов.

## Возможности

- **Создание героя:** расы, профессии, развитие навыков и планирование до 55 уровня (включая будущую экипировку).
- **Образ героя:** 14 слотов, предметы, заточка, стихии и совместимые души. Настройки персонажа не изменяют игровые данные.
- **Книга героя:** расчёты и пояснения, относящиеся к текущему билду. Непроверенные игровые механики не выдаются за подтверждённые.
- **Энциклопедия:** предметы, навыки, души, монстры, сундуки, локации, награды и связанные записи.
- **Мои билды:** аккаунт для облачной библиотеки, сохранения, сравнения и обмена ссылками. Гость может редактировать текущего героя без регистрации.
- **Администрирование:** проверка изменений игрового каталога, редактируемые RU/EN подписи, безопасная публикация проверенных данных в Cloudflare D1.

## Как устроена публикация

Статический интерфейс публикуется через **GitHub Pages** из ветки `bonaqu_projects`. Серверная часть — **Cloudflare Worker + D1**. Публикация сайта не означает автоматическое обновление Worker или D1; игровые значения хранятся отдельно от UI.

Каталог на сайте использует согласованный опубликованный снимок D1 при его доступности, иначе — встроенные файлы `data/os/`. Актуальность и точность отдельных расчётов оцениваются по подтверждённым данным и тестам, а не по одной версии интерфейса.

## Разработка и проверка

```bash
npm test
npm run test:browser
npm run release:check
```

Публикация изменений выполняется через PR с обязательными проверками **Node + Chromium**. После выпуска отдельно проверяются GitHub Pages, Worker и D1 без записи игровых данных. Подробный порядок — в [правилах репозитория](docs/REPOSITORY_OPERATIONS_AND_FAST_DELIVERY.md).

**Безопасность:** не добавляйте в публичные файлы пароли, токены администратора и Cloudflare API credentials. Настройка прав и серверных секретов описана в [инструкции Worker](worker/SETUP_RU.md).
