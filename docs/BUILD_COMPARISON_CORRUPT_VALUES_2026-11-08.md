# Сравнение билдов A/B: повреждённый выбор — не действительное значение

Версия 0.490.0 различает отсутствующее историческое поле и явно повреждённое значение. Для пола, титула, автоматического мастерства, профиля и списков сопротивлений применяется «—» вместо фиктивной настройки. Разные неизвестные расы и профессии остаются разными в «Только отличия» без показа ID. Точные строковые числа 0/1 распознаются в соответствующих исторических полях. Сохранения, D1 и формулы не меняются. Регрессии RU/EN: `tests/build-comparison-corrupt-identity.test.mjs`.
