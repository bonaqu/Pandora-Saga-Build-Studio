# 0.773.0 — новые конкретные стихийные попадания по Гигантскому огру

## Официальные источники
- [Публичный расчёт Pandora Saga OS](https://pandorasaga-os.com/assets/BuildCalculator-DBaXruFa.js), функции `Et`, `kt`, `Ie`, `ve`, `Tt` и массив вероятностного разброса `_e`. Это опубликованный игровой веб-калькулятор, не данные измерений непосредственно в клиенте.
- `data/os/skills.json` (ID, тип, действие/поддействие, `fv1/fv2`, ключ характеристик, обязательное зелёное мастерство, необходимый уровень), `data/os/classes.json` (предел веток и классы), `data/os/monsters.json` (цель ID 22104), `data/os/tables.json` (`lvModify`, `magicPlus`), `data/os/strings.en.json` (официальные английские названия).
- Новые умения: 330001001 Святая стрела / Pure Arrow (свет, INT, Изгнание 8); 410011001 Ледяные осколки / Hailstone (холод, INT, Стихия 8, дополнительное онемение); 410012001 Ледяное копьё / Ice Spear (холод, INT, Стихия 21, дополнительное онемение); 410021001 Удар молнии / Shock (молния, INT, персонаж от 12 уровня, дополнительное падение); 410023001 Громовой разряд / Thunder Crash (молния, INT, от 20 уровня); 420003001 Песчаный вихрь / Sandstorm (чары, SPI, Чары 12, дополнительный сон). Имена берутся из JSON игрового клиента; общие описания и механики статусов не добавляются в Книгу героя.

## Алгоритм
`P = floor(fv1[0]*powerStat/1000)+floor(fv1[1]*level/1000)+floor(fv1[2]*green/1000)+fv1[3]`. Далее `kt(INT,P)` с банковским округлением. Разброс `Ie` по исходному OS: огонь 10%, холод 20%, молния 50%, чары 0%, свет 25%, тьма 25%; бонусы экипировки, душ, накопительных ступеней заточки, подходящего элемента магической заточки и выбранных союзных чар; огр: уровень 53, магическая защита 0, общий магический резист 17, сопротивления огню/холоду/молнии/чарам/свету 0, тьме -25, СПИ 18. Для героя 45 уровня разница +8 даёт дополнительное поглощение 4 и 24% ограничений нижнего/среднего результата. `EP_ELEMENT_BONUS` распространяется только на первый/второй/третий элемент: огонь/холод/молния.

Для единого контрольного ИСКУССТВЕННОГО героя Колдун 45 уровня с ИНТ 80, СПИ 50, Стихия 70, Изгнание 20, Тьма 25 и Чары 20, без экипировки и бафов, min/avg/max:
- Святая стрела: 2 / 10 / 17
- Ледяные осколки: 1 / 7 / 11
- Ледяное копьё: 12 / 56 / 79
- Удар молнии: 1 / 10 / 22
- Громовой разряд: 4 / 30 / 54
- Песчаный вихрь: 4 / 18 / 23.

Все числа рассчитаны для **одного прямого попадания**. Они не утверждают время, вероятность онемения, сна или падения. Огненная буря, Неотвратимый взрыв, Гниение не представлены как полный урон одного применения: дополнительный эффект не подтверждён. При изменении любой сигнатуры игрового навыка результат скрывается, а не дополняется предположением.
