# Энциклопедия — измерение больших списков и двуязычного поиска

Дата: 7 ноября 2026. Тип проверки: **headless Chromium в GitHub Actions на Linux**, с локальным сохранённым OS-снимком и заблокированными внешними HTTP-запросами. Это **не** проверка на ПК пользователя, не сетевой тест Cloudflare D1 и не измерение доступа из РФ без VPN.

## Исходные измерения до расширения теста

| Снимок CI | CPU исполнителя | Раздел | Строк после «Показать ещё» | P95 добавления (мс) | P95 поиска (мс) |
|---|---|---|---:|---:|---:|
| Версия 0.411.0 ([Actions #42361164748](https://github.com/bonaqu/Pandora-Saga-Build-Studio/actions/runs/42361164748)) | AMD EPYC 9V74 | Экипировка | 563 | 18,2 | 114,0 |
| 0.411.0 | AMD EPYC 9V74 | Монстры | 514 | 16,5 | 104,8 |
| 0.411.0 | AMD EPYC 9V74 | Души | 112 | 6,4 | 106,5 |
| Версия 0.412.0 ([Actions #42362881608](https://github.com/bonaqu/Pandora-Saga-Build-Studio/actions/runs/42362881608)) | AMD EPYC 9V45 | Экипировка | 563 | 16,5 | 109,5 |

**Не делать выводов о приросте скорости между этими запусками:** использовались разные CPU. Поиск включает запланированную 100-мс задержку ввода; цифры порядка 100–110 мс **не равны** чистому времени фильтрации в JavaScript.

## Измерено после расширения: пять глав

GitHub Actions: [Chromium #42363634003](https://github.com/bonaqu/Pandora-Saga-Build-Studio/actions/runs/42363634003). Среда: **Intel Xeon 6973P-C, Linux x64, headless Chromium**, локальные OS-файлы, внешние запросы заблокированы.

| Раздел | Развёрнуто записей | Нажатий «Показать ещё» | P95 добавления (мс) | P95 поиска пустого результата/сброса (мс) | P95 поиска с совпадениями (мс) |
|---|---:|---:|---:|---:|---:|
| Экипировка | 563 | 5 | 14,7 | 111,9 | 111,5 |
| Предметы эффектов | 67 | 0 | — | 109,9 | 106,5 |
| Монстры | 514 | 5 | 18,3 | 103,9 | 104,2 |
| Навыки | 232 | 2 | 14,4 | 114,6 | 114,6 |
| Души | 112 | 1 | 5,0 | 106,2 | 105,8 |

Метрики поиска включают штатный **100-мс debounce**. P95 для поиска с совпадениями основан на **двух** повторениях для каждой главы (это ориентир, не статистически надёжный прогноз). P95 добавления — по фактически доступным кнопкам; «—» означает, что все записи помещаются на одной странице. В главе «Навыки» измеряется выбранная по умолчанию категория навыков персонажа, **не все 569 исходных навыков**. Эти замеры не подтверждают прирост скорости после 0.412.0: CPU и загрузка CI могут различаться.

## Следующий охват

Расширенный регрессионный тест дополнительно проходит «Предметы эффектов» и «Навыки», измеряет не только заведомо пустой поиск, но и запрос с реальными совпадениями (по русской букве «а»). Выводит P50/P95 для всех пяти глав и число реально выведенных строк. Подсказки, доступность полей, игровое содержимое и режимы списка/сетки не меняются.

Источники: `tests/browser-encyclopedia-performance.mjs`, лог `Chromium encyclopedia performance:` в GitHub Actions. Результаты запуска нового сценария необходимо сравнивать внутри сходной среды; для проверки на слабом устройстве нужен отдельный локальный тест с воспроизводимыми параметрами, без предположений о производительности Windows/мобильных браузеров.

**Область безопасности:** никакой записи в D1, отправки игровых данных, изменения серверных коэффициентов или сетевого тестирования с приватными токенами.
