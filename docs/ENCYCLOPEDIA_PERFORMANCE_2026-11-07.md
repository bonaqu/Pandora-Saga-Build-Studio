# Энциклопедия — измерение больших списков и двуязычного поиска

Дата: 7 ноября 2026. Тип проверки: **headless Chromium в GitHub Actions на Linux**, с локальным сохранённым OS-снимком и заблокированными внешними HTTP-запросами. Это **не** проверка на ПК пользователя, не сетевой тест Cloudflare D1 и не измерение доступа из РФ без VPN.

**Не делать выводов о приросте скорости между этими запусками:** использовались разные CPU. Поиск включает запланированную 100-мс задержку ввода; цифры порядка 100–110 мс **не равны** чистому времени фильтрации в JavaScript.

## Следующий охват

Расширенный регрессионный тест дополнительно проходит «Предметы эффектов» и «Навыки», измеряет не только заведомо пустой поиск, но и запрос с реальными совпадениями (по русской букве «а»). Выводит P50/P95 для всех пяти глав и число реально выведенных строк. Подсказки, доступность полей, игровое содержимое и режимы списка/сетки не меняются.

Источники: `tests/browser-encyclopedia-performance.mjs`, лог `Chromium encyclopedia performance:` в GitHub Actions. Результаты запуска нового сценария необходимо сравнивать внутри сходной среды; для проверки на слабом устройстве нужен отдельный локальный тест с воспроизводимыми параметрами, без предположений о производительности Windows/мобильных браузеров.

**Область безопасности:** никакой записи в D1, отправки игровых данных, изменения серверных коэффициентов или сетевого тестирования с приватными токенами.
