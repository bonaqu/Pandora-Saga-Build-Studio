# 0.974.0 · Устойчивость — три отдельных коэффициента из Pandora Saga OS

Действующий `data/os/skills.json` содержит умение **260007001 Устойчивость**: `EP_IMMUNE_TUMBLE` TARGET `[0,0,0,15]`, `EP_IMMUNE_STUN` TARGET `[0,0,0,15]`, `EP_IMMUNE_NUMB` TARGET `[0,0,0,15]` и отдельно `EP_IMMUNE_NUMB` **CASTER** `[0,0,0,15]`. `fv2` пуст у всех четырёх.

Раньше код проверял жёсткое `+15`, не позволяя актуальным изменённым величинам служить источником. Кроме того, в панели эффектов было зафиксировано название «По +15». Теперь **те же данные OS** являются источником каждой компоненты. Книга героя, сопротивление выбранного персонажа и панель Эффектов используют один `wardingStatusPassive`. Умение доступно только профессии с `warding` cap ≥26, выученным зелёным мастерством ≥26 и соответствующим исходным классовым требованием.

Проверка **полной четвёрки** отбрасывает новый EP, изменение направления TARGET/CASTER, неправильное FV2, лишний эффект, отсутствие эффекта, изменённые требования/класс/уровень. CASTER-заморозка **не добавляется** в сопротивление вторично; для неподтверждённого несовпадения её величины с TARGET код скрывает всю модель. Для отличающихся трёх TARGET-чисел интерфейс показывает их по отдельности, а не произвольное первое число как общее.

Переменные исходные коэффициенты **доказаны JSON текущего OS**, но не доказывают итоговые серверные шанс наложения/сопротивление или порядок суммирования с другими эффектами. Поэтому результат `modelOnly` и `uncertain`. Никаких записей production D1, Worker/CAS или сохранений, игры и предметов не меняли.

Тесты: `tests/os-warding-fv-source-974.test.mjs`, 28 классов × 6 зелёных значений и 12 атакующих изменений на тестовых копиях. Полный Node, Chromium и live read-only проверки после PR обязательны. #476 остаётся открытой.
