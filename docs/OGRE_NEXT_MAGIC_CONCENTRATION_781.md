# 0.781.0 · Следующее магическое попадание Колдуна по Гигантскому огру

## Источники
- Текущий OS `data/os/skills.json`: 410000101 «Сосредоточенность / Concentration», класс WARLOCK (Колдун), уровень 45, `MYSELF`, три эффекта:
  - `EP_ELEMENT_DAMAGE_SCALE TARGET fv1=[0,0,30,20]`: 20 + floor(30 × зелёная Магия стихий / 100) процентов урона следующей магической атаки.
  - `EP_ELEMENT_BONUS TARGET fv1=[0,0,0,30]`: +30 пробития сопротивления огню, холоду или молнии (не тьме).
  - `EP_LOST_ELEM_ATK_END TARGET fv1=[0,0,0,0]`: расходует эффект на следующей атаке.
- База пересчёта: [публичный калькулятор Pandora Saga OS](https://pandorasaga-os.com/assets/BuildCalculator-DBaXruFa.js), существующая `Et→kt→Ie→ve→Tt` ветвь и `pandora-studio-target-damage.js`. Физическую АТК или показатель МАТК напрямую к стихийному удару не добавлять.
- Исходное «Магические знания» +20% остаётся отдельной пассивкой у классов, для которых действительно подтверждено.

## Игроку
- Книга героя → **Усиления** → **Личные умения**: один переключатель без нового раздела. Доступен только соответствующему Колдуну.
- **Эффекты умений**: каждый урон по огру означает одно **следующее** попадание именно выбранного умения, если перед ним включить Сосредоточенность, а не сразу серию всех показанных навыков. Пересчитываются обе части бафа плюс все ранее поддержанные характеристики/вещи/союзники.
- **Подробнее**: точная разница среднего попадания с/без этого усиления при прочих равных. Значения, не зависящие от текущего билда, рецепты и материалы — только в Энциклопедии.
- У устаревших записей и неподходящих классов выключить влияние, не выдумывать бонусы; сам переключатель в форме остается видим лишь при полном совпадении OS источника.
- Эти вычисления — проверенная по источникам модель, не воспроизведённое измерение игрового клиента.
