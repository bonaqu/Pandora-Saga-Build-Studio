# Энциклопедия Pandora Saga — визуальный аудит и единые компоненты

**Дата:** 2026-11-05. **Объект:** GitHub Pages, `pandora-studio-app.js`, `pandora-studio-honor-view.js`, `pandora-studio-theme.css`, `pandora-studio-wiki-polish.css` и `pandora-studio-honor.css`.

## Цель
Связанная игровая сущность должна выглядеть и вести себя одинаково при переходе из разных глав. Утверждённый удачный образец — *Места появления* в карточке монстра: карточки-ссылки в `.wiki-entity-flow`, с целой кликабельной поверхностью, без лишних стрелок, с понятной подсветкой наведения и клавиатурного фокуса. История «← Назад» возвращает на точное место предыдущей статьи.

## Принципы дизайна (переиспользовать, не копировать)

1. **Связанные записи:** `.wiki-entity-flow` + `a.wiki-link`. Это основной компонент перехода между локациями, монстрами, NPC, войнами и другими записями. В «Чести» допустим уточняющий класс `.wiki-entity-reference`, но не отдельная система текстовых кнопок.
2. **Семантика:** только существующие сущности каталога, ссылка на всю карточку. Не создавать дубли или фиктивные карты из PvP-войн. Несвязанное значение — обычный неактивный текст, а не сломанная ссылка.
3. **Фактура:** тёмный фон, мягкий бронзовый контур, контрастная читаемая надпись, одинаковые hover/focus/active. Без ярких декоративных теней или скачущих анимаций.
4. **Иерархия:** заголовки подразделов отделены тонкой линией, списки компактные, информационные блоки не повторяют подписи; игровые данные всегда важнее декоративности.
5. **Мобильная версия:** локации и войны переходят на следующую строку при нехватке ширины; не создавать горизонтальный скролл; карточка-ссылка имеет высоту не меньше ~34 px.
6. **Редактирование:** owner-select, `+ Добавить`, удаление, инлайн-редактор при двойном клике и D1-связи остаются на месте. В режиме просмотра не показывать технические ID или подсказки разработчика.
7. **Предпросмотр:** использовать уже существующие подсказки предметов. Не встраивать всплывающие карточки внутрь scroll-контейнеров и не менять размер ссылки при наведении.
8. **История:** одна кнопка `← Назад` / `← Back` в левом верхнем углу карточки. Сохранять предыдущую главу, положение статьи, скролл списка и фильтры.

## Выполнено и границы проверки
В этом пакете меняются визуальные стили на общем уровне и отрисовка «Чести»; данные D1, формулы, шансы сундуков и рецепты не затрагиваются. Статические тесты проверяют общий компонент и отсутствие старых текстовых ссылок в «Чести»; Chromium покрывает десктоп/мобильную ширину, ссылки, ранг/награды, скроллинг, историю и RU/EN. Полный браузерный набор покрывает другие интерактивные функции.

**Последующие независимые задачи, не подменяемые косметикой:** реальный замер производительности крупных списков на слабом устройстве, проверка записи owner-изменений в production D1, ручная проверка контраста/доступности на реальных браузерах и глубокая сверка игровой энциклопедии с сервером. Не заявлять их выполненными без отдельных результатов.
