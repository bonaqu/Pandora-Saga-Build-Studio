# 0.764.0 · Книга героя показывает только числа текущего билда

## Книга героя и Энциклопедия
В 0.763.0 в «Эффекты умений» рядом с рассчитанными лимитами ОМ ошибочно попали общие сведения о рецептах, времени и перезарядке. В этом релизе раздел «Расчёт материалов» оставляет **только** числа текущего героя: доступное число применений из полного ОМ, остаток ОМ, суммарно необходимые ингредиенты на это число применений и прирост максимального ОМ до ещё одного применения. Без положительного результата раздел не показывается. Не показываем чужие рецепты и недоступные навыки.

Общая стоимость, время применения, перезарядка, что создаёт навык, предметы на один акт и связанные действия остаются в Энциклопедии. В Книге героя они больше не дублируются. В «Подробнее» убраны и прочие общие описания умений, исходное время/откат и сведения без расчёта по текущему персонажу. Числовые показатели от реальных статов, будущие пороги и эффекты союзников на текущего героя сохраняются.

## Расчёт для прямых лечащих умений
Новая функция directHealingBudget требует доступное собственное прямое лечение с уже рассчитанным объёмом на применение и подтверждённым ID источника. Число применений = floor(полный ОМ героя / базовая стоимость ОМ). Сумма на одну цель = объём лечения за применение × число применений.

Пример: Клирик, уровень 45, ИНТ 70, СД 95, Исцеление 41, 450 ОМ. «Первая помощь» = 264 ОЗ на применение, 28 ОМ. Из полного запаса возможны 16 применений: суммарно 4 224 ОЗ на одну цель, остаток 2 ОМ. Следующее применение — при 476 ОМ, то есть ещё +26 ОМ к запасу. Не выдавать этот суммарный потенциал за реальное восстановление сверх недостающих ОЗ.

Групповое лечение не умножается на неизвестное число игроков. Периодическое восстановление не умножается на неизвестную продолжительность, а каждый подтверждённый 2-секундный тик сохраняется как отдельный показатель.
