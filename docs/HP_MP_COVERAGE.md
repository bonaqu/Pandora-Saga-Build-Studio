# ОЗ и ОМ: источники, покрытие и пределы точности

**Актуализация:** 2026-10-31 (Build Studio 0.83.0). Документ для разработки, не игровой факт вне указанных источников.

## Подтверждённые источники

- Pandora Saga OS: `/gamedata/classes.json` — классовые коэффициенты `hp.base/lv/vit`, `mp.base/lv/spi` (28 классов).
- Pandora Saga Simulator Remaked: `modern/current-vitals.js`, версия Modern 4.25 — базовое значение класса округляется **вниз** из сотых; проценты вычисляются **по базовому ОЗ/ОМ**, отдельно для каждого источника; «Знак жизни» добавляет 250 ОЗ + 15% базового ОЗ.
- Снимки Pandora Saga OS `data/os/items.json` и `data/os/souls.json`: базовые эффекты и игровые описания улучшений. Для некоторых предметов за каждые N уровней улучшения явно написаны прибавки.
- `data/os/skills.json`: «Сила гильдии» и «Дух гильдии» I–VI (2/4/6/9/12/15% для соответствующего ОЗ/ОМ).

## Реализовано в Build Studio

1. Раса + базовая профессия + вложенные очки, затем распознанные плоские бонусы ВЫН/СД предметов и душ.
2. Расчёт базового ОЗ/ОМ по коэффициентам текущего класса, с целочисленным вычислением сотых и `Math.floor`.
3. `EP_MAXLIFE_CONST`, `EP_MAXMANA_CONST` — фиксированные прибавки, не включаемые в базу для процентов.
4. `EP_MAXLIFE_SCALE`, `EP_MAXMANA_SCALE` — самостоятельные проценты от базового ОЗ/ОМ, без сложного процента и повторного умножения на фиксированную прибавку.
5. Влияние ряда явных условий улучшения из игровых описаний (за каждые N уровней, начиная с +N), когда указан ОЗ, ОМ, ВЫН или СД. Не парсятся другие свободные тексты, отсутствующие/неоднозначные условия или неподтверждённые формулы.
6. Выбранные пользователем усиления гильдии ОЗ и ОМ независимо (0–6) и «Знак жизни» (галочка). По умолчанию выключены; их невозможно автоматически считать действующими только на основании имени гильдии/класса.
7. Существующие билды остаются совместимы: сохранённые `state.stats` — вложенные очки, новая опциональная настройка `state.vitalsBuffs` не меняет их.

## Чего пока нет — нельзя заявлять 100%-ное соответствие персонажу в игре

- Полные структурированные бонусы комплектов и всех редких условных предметов.
- Условия и эффекты всех активных/пассивных умений, временных баффов, сторонних участников группы и серверных событий.
- Все нестандартные руны, камни, обменные свойства, заточка без однозначного численного эффекта в доступных данных.
- Подтверждение актуальности всех локальных каталогов относительно живого игрового сервера после даты снимка.

**Проверка полного соответствия:** сопоставлять реальные снимки клиента для каждой комбинации с `hpBase/mpBase`, `vitalsBonus.hp/mp`, эффектами экипировки, душ, уровнем заточки, активными баффами. Изолированные тесты доказывают корректность реализации документированных правил, но не все механики на сервере.

## Примеры для проверки

- Клирик 45, ВЫН 49 и СД 53 без усилений: **3145 ОЗ / 1279 ОМ** (эталон Remaked Modern 4.25).
- Высокая душа: +1 СД применяется до расчёта базовой ОМ, затем +8% к уже пересчитанной классовой базе.
- Прочная палица викинга: заточка +6 даёт +45 ОЗ за три полных шага по 2; на +7 появляется дополнительная ВЫН +1; базовая ВЫН самого предмета не теряется.
- Гильдия и «Знак жизни»: проценты считаются отдельно от классовой базы, не от окончательного значения со всеми вещами.

Остальные механики остаются приоритетом ROADMAP до появления достоверных источников и эталонов клиента.
