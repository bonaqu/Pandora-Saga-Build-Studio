# Назначение глав Книги героя — Remaked Modern / Build Studio

Проверено по исходникам [Pandora Saga Simulator Remaked `js/ini.js`](https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/blob/bonaqu_projects/js/ini.js), [`js/create.js`](https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/blob/bonaqu_projects/js/create.js) и [`modern/adapter.js`](https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/blob/bonaqu_projects/modern/adapter.js). В Modern это **три разных массива**, а не три вида одной таблицы.

| Книга героя | Источник Remaked | Что показывать | Чего не показывать |
| --- | --- | --- | --- |
| Результаты расчёта | `Set.Status` → `#StatusView` (43 поля) | Только общий финальный показатель, единица и неизвестное «—» | Уравнения, коэффициенты, копии во вкладках |
| Атака | `Set.ATK` → `#ATKView` | Отдельный урон оружия, ауры, магия каждой стихии, статусы при атаке, бонусы дальности, условные срабатывания | Повтор финальных АТК, точности, крита, скорости, отката, скорости движения |
| Защита | `Set.RES` → `#RESView` | Натуральное восстановление ОЗ/ОМ, скорость восстановления, сопротивления конкретным состояниям и отдельные защитные эффекты | Повтор финальных DEF, уклонения, общих сопротивлений стихиям, входящего урона |
| Усиления | `Set.Buff` → `#BUFFView` | Настройки гильдии, титула чести, жреца и наложенных боевых эффектов | Повтор чисел ОЗ/ОМ из результатов, дубль переключателя зелья |
| Эффекты умений | `#SkillView` | Результаты конкретных навыков лечения/регенерации и доступные песни | Повтор выбранных усилений, эффекты оружия и расходников |
| Эффекты зелий | `#POTView` | Восстановление от зелий, расходников ОМ и ОЗ, отдельные предметы снятия состояний и запуска умений | Повтор общей эффективности зелий из 43 результатов |

**Границы:** Build Studio не имитирует все исторические поля `Set.ATK` и `Set.RES` — например, урон по каждому виду монстров, шансы редких дебаффов и полные характеристики верхом требуют независимых источников/проверок. Отсутствующие правила не заполняются нулями и не «достраиваются» из смежного показателя. Из известных данных показываются только отдельные поля, а повторные составные бонусы не суммируются без проверенного правила.

**Дедупликация:** стихийная заточка от предмета 1862 отображается только в блоке стихийной магии раздела «Атака»; условное огненное оружие — только в его раскрываемой группе в «Атаке», совпавшая строка магии не добавляется второй раз. `EP_RACE_RANGE` и `EP_RACE_CARRY` дают одну расовую запись. Предметные проки отделены по направлению события (при ударе/при получении урона), подтверждённые описания не дублируются generic-проками. Неизвестная результативная боевая арифметика остаётся без ложных итогов.

**Проверки:** `tests/hero-independent-effects.test.mjs` проверяет раздельные источники и реальные классы/предметы, `tests/browser-smoke.mjs` открывает главные разделы и проверяет количество итогов/отсутствие дубликатов. Сверка чисел с реальным текущим клиентом OS по-прежнему не закрыта.
