# 0.785.0 · Текущая цель боя вместо единственного фиксированного огра

## Установленные данные

В `data/os/monsters.json` проверено 702 записи; каждая содержит числовые уровень, ОЗ, СД, защиту, магическую защиту и сопротивления по девяти школам. Новые игровые значения не придумываются: при работе с текущим сервером берётся подтверждённый снимок production D1, при осознанном архивном режиме — архивный `data/os/monsters.json`. RU-имена из той же записи, EN — из OS `strings.en.json`.

Действующий публичный [Pandora Saga OS BuildCalculator](https://pandorasaga-os.com/assets/BuildCalculator-DBaXruFa.js) вычисляет одно попадание через `Et → kt → Ie → ve → Tt`. Сопротивления, поглощение от СД/защиты, поправка разницы уровней и конечные округления зависят от выбранного противника, но не требуют отдельной формулы для каждого имени монстра.

## Изменения

- `pandora-studio-target-damage.js`: `monsterFromSource` строго проверяет выбранный ID и полный профиль в том же снимке; отсутствие/повреждение записи возвращает недоступность результата без возврата к огру. Дефолт 22104 сохранён для существующих билдов и standalone регрессий. `availableMonsterTargets` допускает только валидные записи.
- `pandora-studio-app.js`: список собирается **один раз при изменении снимка D1 или EN-переводов**, а не на каждое изменение характеристик. Каталог монстров загружается лениво только после открытия главы «Эффекты умений». Выбранный `selectedDamageTargetId` — локальный выбор представления, не записывается в сохранения, D1 или аккаунты.
- `pandora-studio-hero-book.js`: один короткий выбор цели `<select>`, русский/английский язык, название и уровень. Переключение пересчитывает прежние числовые результаты и сохраняет фокус/прокрутку на этой главе; новых блоков нет.
- Никаких новых боевых формул и значений для неподтверждённых цепочек `410004001` «Неотвратимый взрыв» и `330061001` «Круг света». У первого недоказана интерпретация задержанного `EP_ELEM_DELAYED_BONUS`, у второго три `EP_ELEMENT_DAMAGE` и изменение сопротивления требуют отдельного подтверждения порядка применения.

## Приёмка
