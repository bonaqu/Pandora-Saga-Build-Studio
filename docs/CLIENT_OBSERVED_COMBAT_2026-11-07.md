# Фактический игровой контроль Pandora Saga OS — 7 ноября 2026

Источник: пользовательский скриншот реального игрового клиента Pandora Saga OS (7 ноября 2026), а не исходные значения публичного веб-калькулятора. На изображении видны **Атака 50–74** и **Защита 47**. Дополнительно игрок сообщил **точность 62, уклонение 52, сопротивление льду 3**. Перезарядка 1,4% и скорость каста 3% не подтверждены отдельным тестом.

Условия: персонаж эльф (женщина), 45 уровень, характеристики не распределены (432 очка свободно); очки навыков не вложены (85 свободно); исходные зелёные значения по веткам: Slash 4, Archery 5, Alchemy 4, Assassin 3, Warding 3. Стартовые характеристики эльфа + линии Scout дают ВЫН3, СИЛ5, ПРВ7 (AGI), ЛВК6 (DEX), СД6, ИНТ7. Точность 62 требует пассивного бонуса линии Archer; конкретная ступень класса не сообщена.

Итог базового AC: `4+18+5+12+5=44`. **Официальная новость №4 текущего сервера** устанавливает для всех шести категорий (щит, шлем, броня, перчатки, штаны, обувь) **+1,2 защиты за уровень заточки** вместо прежних +1,5. Для поножей +3: `12 + 3×1,2 = 15,6`, игровой интерфейс предмета показывает `12+3` (технически обозначение заточки), сумма защиты персонажа `44 + 3,6 = 47,6`, отображается **47** с отсечением дробной части. Это не исключение для поножей, а общее правило.

Верх атаки: `floor(СИЛ 5/2)+W67+2+3=74`. Нижняя атака **50** наблюдалась в клиенте. Универсальная формула минимума остаётся неизвестной: архивные источники связывают его с обученным мастерством подходящей ветки. Нельзя механически применить коэффициент к каждому оружию.

Точность: `45+6 +10+floor(15/10)=62`. Уклонение: `45+7=52`. Сопротивление льду: `3` из плаща.

Сохранён и более ранний прямой игровой эталон от 13 октября 2026: эльф/воин 1 уровня, короткий меч ID21, туника ID12001, штаны ID13001, обувь ID15061 — АТК **9–12**, DEF12.

## Политика вычисления после новости сервера №4

- **Нет исключений для железных поножей**: все шесть категорий заточки брони и щита получают +1,2 защиты за каждый уровень +1…+10. Дробные остатки нескольких вещей складываются до итогового округления вниз. В коде храним десятые в целочисленном виде, чтобы не копить погрешности от последовательных округлений.
- Физическая атака от оружейной заточки берётся из текущего `tables.weaponPlus`, а не из старой японской таблицы. Проверенные новые +7: 15% +19, +8: 18% +23, +9: 21% +27, +10: 25% +32.
- Магическая атака от *магической* заточки берётся из текущего `tables.magicPlus[grade].ratio`: +1…+10 = 1/3/5/8/11/15/19/23/27/32 процентов. Отдельный `magicPlus.flat` не был объяснён в новости: не добавляем его к итоговому МАТК как дополнительный бонус без отдельного доказательства.
- Только полностью подтверждённые игровые комплекты дают нижний предел АТК до установления общей формулы. Для остальных билдов нельзя придумывать универсальный коэффициент.
- Не модифицировать production D1 и не переписывать базовые свойства каталога предметов ради исправления формул. В сохранённых билдах остаются прежние значения заточки.
- Остаются отдельные проверки порядка округления активных бафов и иных процентных источников на нескольких заточенных вещах (не подмена действующего общего правила).
