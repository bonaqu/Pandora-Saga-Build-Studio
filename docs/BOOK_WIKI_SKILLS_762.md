# 0.762.0 · Книга героя и удобная Энциклопедия

## Эффекты текущего героя
Для доступного числового активного навыка с базовым `cast>0` теперь внутри **существующего** «Подробнее» видно примерное время применения с включённым союзным «Воодушевлением»: 50% от базового `cast`. Применяется уже проверенная для лечения 50%-модель Remaked `Status_78` / OS `320006001`, а не предположения о скорости заклинаний, серверном округлении или совместной работе иных усилений. Строка отсутствует у мгновенных, пассивных и недоступных текущему герою навыков. Никакого списания ОМ, изменения характеристик или сохранений.

## Навигация навыков и связи с предметами
В Энциклопедии доступны ссылки **«Следующее умение»** по точному `prereq` и общей разрешённой профессии предыдущего и следующего изучаемых навыков. Например, `110101001` «Двойной удар» / Slice → `110101002` «Порез» / Dice. Для внутренних действий и недоступных профессиям версий связь не подменяется.

Обратные связи предметов по реальным `EP_CONSUME_ITEM`/`EP_ADDITION_ITEM` сохранены, в том числе рецепты и все ингредиенты с количеством. Стандартные изучаемые умения доступны сразу, специальные/внутренние действия собраны в обычное раскрытие «Дополнительные действия». Например, карточка «Жадеит» `70003` содержит пять внутренних «Магистр чести», но список не загромождает страницу по умолчанию.
