# Книга героя: ближайший реальный прирост исцеления от уровня (0.754.0)

## Расчёт по доступному текущему герою
Для каждого навыка в собственных «Лечащих умениях» уже проверены его профессия, зелёное Исцеление, текущий уровень, исходный OS ID и сигнатура. Новый шаг: вычислить величину по той же модели на следующих целых уровнях до 55 и вывести только первый уровень с **действительным приростом целого результата**.

- Прямое лечение: `floor((const+INT*a/100+level*b/100+Healing*c/100)*healingEffectiveness/100)`.
- Восстановление 310022001: `const+floor(SPI*a/100)+floor(level*b/100)+floor(Healing*c/100)`.
- Модель источника, а не доказательство точного поведения живого сервера. Сохраняются прежние текущие условия изучения и разделение собственной/союзной магии.

## Проверяемые примеры
- Клирик 45 уровня с ИНТ 70, СД 95, Исцелением 41: «Первая помощь» 310001001 получает **+3 ОЗ на уровне 46**.
- Клирик 39 уровня с теми же СД и Исцелением: «Восстановление» 310022001 — **27 → 28 ОЗ за срабатывание на уровне 40**.
- «Храм» 310023001 → 310023002 не имеет зависимости от уровня в числовом векторе: ложная прибавка не появляется.
- На 50 уровне Клирика ОС меняет 310001001 → 310001002 и другие улучшенные варианты. Для героя ниже 50 прогноз текущей версии ограничен 49 уровнем; с 50 расчёт нового ID выполняется отдельно.

Один бонус показывается «за применение», другой — «за срабатывание»; собственная регенерация ОМ сохраняет подпись ОМ. Сохранения и Cloudflare D1 не меняются.
