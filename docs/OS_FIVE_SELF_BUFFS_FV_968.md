# 0.968.0 · Пять личных усилений: текущие коэффициенты OS вместо зашитых значений

Действующий `pandorasaga-os.com/gamedata/skills.json` — авторитетный источник **экспортированных параметров**, но не исходник скрытых серверных механик. Пять навыков существуют в проверенном сохранённом снимке каталога Build Studio.

| ID | Название | Источник | FV1 |
|---|---|---|---|
| 142051001 | Хладнокровие | `EP_CRITICALRATE_CONST` | `[0,0,20,10]` |
| 260005001 | Быстрое уклонение | `EP_AVOIDANCE_CONST` | `[5,0,15,10]` |
| 260008001 | Ускользание | `EP_AVOIDANCE_CONST` | `[0,0,0,100]` |
| 260002001 | Лёгкость | `EP_MOVESPEED_SCALE` | `[0,0,0,30]` |
| 213702001 | Стремительная стрела | `EP_ATTACKINTERVAL_SCALE` | `[0,0,0,30]` |

Эти пять моделей **не** используют старые цифровые константы в коде. Например, Хладнокровие использует `fv1[3] + floor(мастерство × fv1[2]/100)`, а Быстрое уклонение использует `fv1[3] + floor(ЛВК × fv1[0]/100) + floor(мастерство × fv1[2]/100)`. Это сохранённый порядок Remaked; серверный клиент ещё не доказал этот порядок в PvP.

Для Ускользания строго требуется отдельный `EP_LOST_WARDING_DAMAGE` с исходным `[0,0,0,2]`. Для Хладнокровия/Стремительной стрелы — существующий нулевой `EP_LOST_CHANGE_WEAPON`. Дополнительные неизвестные FV2, новые эффекты и изменённые направления **отменяют числовую модель**, даже когда основное `fv1[3]` похоже на известное.

Существующие ограничения профессии, оружия, мастерства и уровня остаются обязательными для `applied`. Новое поле `choices.counted` сообщает только о наличии распознаваемой формулы, не о том, что эффект активен или полностью подтверждён игровым сервером.

Проверки: `tests/os-five-self-buffs-fv-968.test.mjs`, полные Node + Chromium; после объединения Pages / Worker D1 read-only. Никаких обновлений сохранённых билдов, продакшен-каталога, Worker или D1.
