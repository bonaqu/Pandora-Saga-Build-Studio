## Механика начальных веток

У каждой корневой профессии есть независимые базовые величины: `D` — начальная зелень, `P` — начальный потенциал ветки. При распределении свободных очков увеличивается **потенциал P + вложенные очки**, а зелёное мастерство может тренироваться вплоть до этого потенциала. Начальная зелень D не расходует очки умений. Исходные значения находятся в `jobInit.<BASE>.branches`, потенциалы — в `classes.<CLASS>.branchCaps`, подтверждаются `Skill.D` и `Skill.P` старого `js/ini.js` Remaked и его `modern/skill-controls.js`.

Пример Воина 1 уровня: Секущий 5/25, Колющий 2/25, Рубящий 5/25, Тяжёлый 2/20, Оборона 4/25, Стрельба 1/5. При этом свободно и вложено по **0 очков умений**.

«Вдохновение» в линии Священник/Клирик/Энчантер: исторический Remaked использует `1 + floor(общая зелень Молитвы / 10)` для добавки СД. «Тактика» даёт бонус к точности по найденному правилу «Орлиный глаз» лишь для линии лучника, а не безусловно для каждого класса; каждые 10 дополнительно натренированных очков этой группы увеличивают этот бонус на 1. Оба правила являются моделями, сверенными с исходником Remaked, но каждая формула должна проверяться с живой игрой при возможности.

## Исправление автозелени 0.388

Потенциал `P` — верхняя граница мастерства, **не** текущее мастерство. Стартовая зелень — `D`; вложенные очки — отдельная величина. Режим автоматической зелени Build Studio теперь не подменяет текущий уровень потолком `P`: на нетронутом Воине 1 уровня выводится `5/25`, а не `25/25` (остальные ветки аналогично). При явных вложениях автоматическая зелень отражает только их, а вручную достигнутый уровень не затирается. Выключение галочки восстанавливает вручную освоенную зелень, не сохраняя автоматический предпросмотр. Это правило переключателя Build Studio соответствует запросу владельца; отдельного идентичного переключателя в оригинальном Remaked нет.
