# Разделение навыков в энциклопедии — 7 ноября 2026

Цель: на первом экране «Навыков» показывать подтверждённые умения персонажа, не смешивая их со служебными эффектами и техническими версиями, но не терять доступ к исходным записям. Критерий «есть картинка» не определяет игровую доступность.

## Семь фильтров

| Фильтр RU / EN | Условия |
|---|---|
| Умения персонажа / Character skills | `learnable===true`, хотя бы одна явная разрешённая профессия (`classes`), не ветки `special/race` |
| Гильдия и осада / Guild and siege | Структурные записи ветки `special` с префиксами ID `600`, `610` и `620`. Включает гильдейские ранги и осадные инструменты, но не выдаёт записи за обычные изучаемые умения |
| Особые умения / Special skills | Записи с назначенными профессиями, которые не подтверждены как обычные изучаемые навыки; не трактуются автоматически как активные |
| Варианты навыков / Skill variants | Скрытые ранее канонизированные записи или дополнительные записи с названием подтверждённого навыка персонажа, даже при ошибочно/неполно выставленном `learnable`; не затрагивает гильдию и осаду |
| Прочие записи / Other records | Системные записи, статусы из технической ветки `race` (например, Сон и Оглушение), неизвестные и прочие неподтверждённые навыки; это не расовые пассивки персонажа |
| Без изображения / Missing artwork | **Независимый срез** всех навыков, у которых нет доступного локального оригинала, одобренной иконки-донoра по `displayAliases` или собственной иконки администратора. Тот же игровой знак вопроса, что в списке |
| Все навыки / All skills | Все записи с их исходными ID, без деструктивной дедупликации |

Категории взаимоисключающие, кроме независимого среза «Без изображения» и «Все навыки».

Гильдейские звания I, II и т.д. **не становятся дублями**, даже если совпадают рисунки. Для варианта персонажа приоритет всегда у `learnable===true` с подтверждённой доступностью профессии.

В сохранённом `data/os/skills.json` на момент разработки: **569 записей**; **234** помечены `learnable:true`, из них **232** имеют явно назначенные профессии. Числа отображаемых групп вычисляются из загруженного реального каталога (D1 или архивной копии) и могут отличаться.

## Дополнительная проверка источников и навигации (0.403.0)

- «Помощь ветра» `260006002` и «Храм» `310023002` имеют `learnable:true`, но пустой список разрешённых профессий. По совпадению имени с подтверждённой доступной версией они теперь относятся к **вариантам**, а не к обычным навыкам персонажа; исходные параметры обеих версий доступны по своему ID.
- Внутренние записи `branch:race` с названиями «Сон», «Оглушение» и подобными хранят статусные/служебные эффекты, а не выбираемые расовые пассивки. Для них более точная группа — «Прочие записи».
- Прямые ссылки на варианты из поиска, других разделов и браузерной истории сохраняют исходный ID даже после перезагрузки страницы. Канонизация монстров, предметов и других разделов осталась прежней.
- Выбранный фильтр навыков теперь входит в навигационное состояние вкладки и сохраняется между возвращением назад, переходами и перезагрузкой. Отсутствующая иконка `skill_unknown.webp` одинаково отображается при наличии записи навыка как в live D1, так и в явно выбранном архивном режиме. Источник оригинала никогда не подменяется.
- Распределение иконок в сохранённой версии: **59** записей навыков остаются без собственного/общего изображения; в интерфейсе для них показывается вопросительный знак. Остальные 201 переиспользуют локальный оригинал для отображения, исходный реестр 264 пропусков не пересматривается.

## Архитектура

- `pandora-studio-wiki-skill-filters.js`: чистая модель классификации, без изменений игровых данных, формул или D1.
- `pandora-studio-encyclopedia-data.js`: опциональный режим `includeVariants` для поиска по *всем* исходным ID. Существующее каноническое отображение, используемое другими разделами, остаётся совместимым.
- `pandora-studio-app.js`: один компактный выпадающий фильтр в существующей строке управления, рядом с поиском. Сохранены прокрутка, поиск RU/EN, нумерация результатов и ссылки. По прямой ссылке открывается нужная категория.
- `assets/os-icon-manifest.json`: подтверждённые 1173 оригиналов, 264 отсутствующих и 201 отображаемое переиспользование **не изменяются**.
- Предоставленные пользователем инструменты извлечения клиента и игровые архивы не публикуются на GitHub автоматически.

### Неопределённость

`learnable` и `classes` отражают известные поля каталога. Они не гарантируют, что способность исполняется на текущем сервере, а отсутствие таких признаков не доказывает обратного. Данные `branch:special` структурно разделены по префиксам текущих каталогов, а не произвольно по рисунку или названию.

Ничего не удаляется, не меняется в серверных данных и не объединяется в формулах. При появлении новых доказательных сведений классификатор может быть уточнён отдельно от индекса навыков.
