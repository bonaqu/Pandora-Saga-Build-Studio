# Мои билды — динамическая локализация (0.484.0)

Карточка выводит русское или английское название расы по текущему языку, не меняя имя сохранённого билда. Поиск в списке принимает обе локализации расы. Подтверждение перезаписи формируется как RU/EN текст до вставки имени билда, потому что словарь точных статических соответствий не может перевести динамическую строку. Подтверждение без нажатия «Confirm overwrite» никогда не изменяет библиотеку и не пишет в D1.

Проверки: Node — исходные выражения и UI-словарь; Chromium — шесть сохранённых билдов, переключение EN, билингвальный поиск, предупреждение и неприкосновенность данных.
