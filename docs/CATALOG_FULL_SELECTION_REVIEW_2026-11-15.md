# Обновление игрового каталога · read-only проверка полного выбора (2026-11-15)

## Что проверяли

Загрузили 17 открытых JSON-разделов текущей игры и сопоставили с публичной активной версией Cloudflare D1. Оба набора получены HTTP GET, без авторизации администратора и без записей. Источник — опубликованные игровые JSON; это **не** независимое доказательство, что реальные серверные механики полностью им соответствуют.

`meta.json` отличается по количествам, источниковым контрольным суммам, английским переводам и предупреждениям. В `tables.json` текущий открытый игровой источник указывает `levelCap=50`, опубликованный сайт — `levelCap=45`; также отличаются две записи `zoneDrops`. В `instances.json` шесть различий относятся к присутствию русских описаний `blurbRu` в D1: они не должны теряться просто потому, что исходный JSON их не содержит. Результаты не предназначены для прямой автоматической публикации.

## Сценарий проверки полного выбора

1. Админ запускает «Проверить изменения в текущей игре». Загрузка получает 17 разрешённых JSON и повторно читает `meta.json` для защиты от смены источника в ходе сверки. Публичные данные D1 читаются со своим номером снимка; не допускается смешение версий. Редактор не пишет D1 при этой операции.
2. «Выбрать все найденные изменения» выбирает все предложенные игровые различия, включая удаление и настройки, но не служебные суммы без изменения игры. Переносы описаний выбираются отдельно как подтверждённая операция; локальные русские описания остаются отдельной галочкой.
3. «Перед применением» показывает количество выбранных изменений, удалений, рискованных полей, ссылок, заменяемые целиком формулы и изменение предела уровня. Для рискованного набора требуется явная галочка осознанной проверки, сбрасывающаяся при изменении выбора или источника. Обычный выбор **не** публикует каталог.
4. Публикация требует повторного подтверждения, подготовки `compose → normalize → auditSelection`, проверки активной версии D1 и `expectedActive` при финальной записи. Пока идёт запись, окно нельзя закрыть.
5. После публикации UI повторно читает актуальную версию и публичный `meta.json`. Только совпадение с новым снимком подтверждает, что новая версия доступна игрокам. Ошибка проверки не называется успешным обновлением игроков, а потеря ответа не считается откатом.

## Ограничения

Проверка серверных хитов, реальных дропов и урона в игровом клиенте не производилась: точное соответствие публичных файлов серверным механикам не заявляется. Никаких записей в production D1 не выполнялось. Проверка браузера использует изолированный симулятор запросов; успешная CI означает корректную работу интерфейса, а не отсутствие расхождений в фактической игровой механике. Видимый обычным пользователям интерфейс не называет сторонний источник данных.
