# 0.771.0 · Проверяемый урон одного попадания умений по Гигантскому огру

## Источники и граница

- Публичный калькулятор текущей Pandora Saga OS: https://pandorasaga-os.com/assets/BuildCalculator-DBaXruFa.js . В минифицированном JavaScript функции `Et`, `kt`, `Ie`, `ve`, `Tt` выполняют вычисление стихийного удара. `Et` выбирает характеристику по `powerStat`, а `Tt` использует ИНТ для общей мощности; не считать, что `powerStat` всегда равен ИНТ.
- Данные навыков: `data/os/skills.json`; классов: `data/os/classes.json`; цель 22104: `data/os/monsters.json`; разница уровней, магическая заточка: `data/os/tables.json`.
- 240005001 — Ползучая ловушка (через 240005003; ОГОНЬ, ЛВК и зелёные Ловушки). Уже была в 0.770.0.
- 410001001 — Огненная стрела (ОГОНЬ, ИНТ, Стихия). Самостоятельный `EP_ELEMENT_DAMAGE`.
- 430001001 — Кража жизни (ТЬМА, ИНТ, Тьма). Итог включает только `EP_ELEMENT_DAMAGE`, НЕ лечение `EP_LIFE_ABSORB`.
- 430052001 — Ядовитый удар (ТЬМА, СД, Тьма). Учитывается только попадание `EP_ELEMENT_DAMAGE`, НЕ периодический `EP_CAUSE_POISON`.
- Не включаем Огненную бурю, Неотвратимый взрыв, Гниение: дополнительное действие/отложенный эффект нельзя выдать за полный результат применения до отдельной проверки его семантики.

## Формула одного удара

Для источникового `fv1 = [a,b,c,d]`:
`P=floor(a×характеристика_умения/1000)+floor(b×уровень/1000)+floor(c×зелёное_мастерство/1000)+d`.
После множителя `INT` из `kt` применяется округление половины к чётному. Разброс по `Ie`: огонь 10%, тьма 25%. Дальше учитываются бонус к стихийному урону экипировки/душ, соответствующая стихии магическая заточка (плоская надбавка плюс процент), только выбранные подтверждённые усиления, сопротивления стихии и половина общего магического сопротивления, поглощение СД и защита цели, затем штраф по разнице уровней.

Важное ограничение: `EP_ELEMENT_BONUS` действует на стихии огонь/холод/молния и НЕ пробивает сопротивление тьме; огненный бонус предмета НЕ прибавляется к урону тьмой; заточка Тьмой НЕ усиливает огонь.

Контрольный искусственный билд: Колдун 45 уровня, ИНТ 80, СД 50, Стихия 50, Тьма 25, без экипировки/бафов. Против огра 53 уровня: Огненная стрела 4 / 21 / 28, Кража жизни 10 / 48 / 71, Ядовитый удар 1 / 5 / 9 (минимум/среднее/максимум); по текущему билду результаты пересчитываются. Это прогноз публичного калькулятора, не реальные измерения боевых попаданий в клиенте.

## Интерфейс и тесты

В Книге героя только навыки, доступные текущему персонажу; один ряд для каждого, min–max и среднее в «Подробнее». Коэффициенты, которые уже представлялись предположительно, заменяются рассчитанным результатом. Без материалов, рецептoв, описаний игры и служебных предупреждений. Энциклопедия остаётся источником справочных сведений. Тесты: `tests/os-target-damage-770.test.mjs`, `tests/os-target-damage-771.test.mjs`, `tests/browser-book-game-terms-664.mjs`. Требуются полные Node и Chromium и независимая проверка публикации.
