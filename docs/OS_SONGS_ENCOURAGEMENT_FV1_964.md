# 0.964.0 — Источниковые коэффициенты песнопений и Ободрения

**Основание:** точный `data/os/skills.json`, совпадающий с актуальным опубликованным `pandorasaga-os.com/gamedata/skills.json` в прямой сверке #831. Исторический Remaked 2E используется для предположительных стадий округления, **не как источник свежих чисел**.

Все формулы вычисляются из `fv1=[атрибут%, уровень%, мастерство%, константа]`, но используются только для тех подтверждённых по форме семейств, у которых отсутствует зависимость от уровня (`fv1[1]=0`). Сумма модельных компонентов: `fv1[3] + floor(SPI*fv1[0]/100) + floor(мастерство*fv1[2]/100)`. Для отрицательного снижения времени/задержки сохраняется историческое `fv1[3] - floor(SPI*(-fv1[0])/100) - floor(мастерство*(-fv1[2])/100)`.

| Источник OS | Текущие FV1 | Применяемая математическая модель |
|---|---|---|
| 320012001 · Ободрение, три TARGET-эффекта | `[0,0,10,0]` каждый | общий бонус СИЛ/ПРВ/ИНТ от Blessing, только при равных трёх векторах |
| 340003003 · Песнь мира | `[60,0,30,10]` | модель порога, SPI + Hymn |
| 340001003 · Песнь поэта, точность/уклонение | `[13,0,13,4]` каждый | одно число только при равных двух FV |
| 340004003 · Песнь чар, стихийная сила | `[8,0,8,4]` | модель прибавки стихии |
| 340004003 · Песнь чар, задержка | `[-28,0,-17,-5]` | отрицательная модель индекса; **не доказанные секунды** |

Все исходные ID, названия семейств `EP_*`, направления TARGET, отсутствие неизвестного `fv2` и полный граф root→SPHERE→ALLY проверяются, прежде чем что-либо показать. Изменённые официальные числовые коэффициенты с **той же семантической структурой** принимаются без изменения JS. Неизвестный слот уровня, смена знака, различающиеся парные эффекты и повреждённая связь — **fail closed**. Временное применение/активация песнопений не включается автоматически.

## Проверки

`tests/os-song-os-fv1-964.test.mjs`: 3 458 комбинаций SPI, Blessing и Hymn, все 28 классов × 55 уровней для источниковой доступности песнопений, положительные изменения подписанных FV1 и отрицательные тесты структурных изменений. Полный PR CI: Node + Chromium; после merge — Pages и Worker/D1 read-only readiness.

**Ограничение достоверности:** подтверждены значения FV и идентичность источника. Применённые ступени `floor` взяты из Remaked, потому что публичные JSON OS не раскрывают внутреннюю реализацию боевого сервера. Это модели, не измеренные фактические результаты; `verified:false`, отсутствие автоматического расхода баффов и сохранность билдов остаются без изменений. Задача #476 остаётся открытой.
