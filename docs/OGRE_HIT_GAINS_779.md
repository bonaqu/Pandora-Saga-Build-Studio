# 0.779.0 — вклад бонусов в средний урон по огру для текущего билда

## Проверенные исходники
Публичный `Pandora Saga OS BuildCalculator`: https://pandorasaga-os.com/assets/BuildCalculator-DBaXruFa.js — `Et → kt → Ie → ve → Tt` для одного пакета стихийного урона. Локальные источники `pandora-studio-target-damage.js`, `data/os/skills.json`, `data/os/tables.json` и реальные предметы/души/комплекты.

## Реальные числовые прибавки
Сохраняем текущие характеристики, профессию, мастерство, оружие/заточку, огра и уровень героя. Для фактического среднего попадания `average` применяем те же шаги расчёта с теми же округлениями и защитой цели. Отдельно пересчитываем:
1. Без `priestSong.sageElementDamage + priestEnchantment.magicRate` (выбранные союзные усиления). `allyAverageGain = current.average - withoutAllies.average`.
2. Без прямых процентов `EP_ELEMENT_DAMAGE_SCALE` и соответствующей стихии из экипировки, душ, порогов заточки и комплектов. `itemDamageAverageGain = current.average - withoutItemDamageRate.average`.
3. Без **только** бонусных процентных и абсолютных значений подходящей стихии из `tables.magicPlus[grade]`. `refinementAverageGain = current.average - withoutMagicRefinement.average`.

Каждый пересчёт независимый. Значения **не складывать в один итог**, поскольку округления, ограничения минимального урона и взаимодействие процентов срабатывают после суммирования бонусов. Сами характеристики вещей (прибавка к INT/DEX и т. п.) уже входят в текущие статы героя и не отменяются в сравнении №2 — поэтому подпись специально **«Бонусы урона вещей»**, не «вся экипировка».

Отображать **только ненулевой результат** (в ОЗ к среднему удару) в уже существующем `Подробнее`; без дополнительной карточки или сервисного текста. В Книге не размещать рецепты, расходники и общие описания умений.

## Недостаточно сведений для итогового урона
`330061001` «Круг света / Holy Rays»: дочернее действие содержит дебафф сопротивления и три записи `EP_ELEMENT_DAMAGE`; реальный порядок их применения относительно сопротивления и возможности последовательных пакетов пока не доказан опубликованным калькулятором. Не публиковать итог 3×.
`410004001` «Неотвратимый взрыв / Time Bomb»: `EP_ELEM_DELAYED_BONUS` на заклинателе и отдельный пакет урона; без подтверждения работы задержки не выдавать общий урон. Источниковое описание остаётся в Энциклопедии.
