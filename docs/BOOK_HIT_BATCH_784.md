# 0.784.0 · Быстрый пересчёт эффектов текущего героя

## Достоверная граница изменения

Существующий расчёт Pandora Saga OS `Et → kt → Ie → ve → Tt` для одного попадания по Гигантскому огру (22104) не менялся. Раньше при построении всего списка изученных атак каждое умение повторно загружало один и тот же профиль монстра и обходило надетые вещи, души, эффекты заточки Forth и бонусы комплектов.

`PandoraOSTargetDamage.supportedSkillHits` теперь создаёт общий снимок **на один вызов**, а разные удары используют его только для чтения. При изменении текущего билда, D1-цели, титула, вещей или усилений следующий вызов строит новый снимок. Индивидуальный `crawlingTrap` работает самостоятельно и должен давать тот же результат.

Выбранные титулы чести 950000003 («Том огня»), 950000004 («Том бури») и 950000005 («Том грозы») проверяются по пяти векторам и всем существенным метаданным актуального игрового каталога. Повреждённое умение не получает старый +5% бонус. Физические эффекты и другие стихии по-прежнему не смешиваются.

## Проверка

`tests/os-hit-batch-784.test.mjs`: три комбинации ЛВК/ИНТ/мастерства ловушки (одиночный против группового расчёта), повторные вызовы со сменой выбранного титула, сопротивления цели из D1, заточки, повреждённые метаданные. Действующие регрессии 0.770–0.783 сохраняются.

Книга героя остаётся компактной: только числовые эффекты текущего билда; никаких новых карточек, рецептов и общих текстов. Неподтверждённые суммарные эффекты «Неотвратимого взрыва», тиков и поглощения не добавлялись. Node + Chromium до объединения PR; после публикации Pages, Worker/D1 только на чтение.
