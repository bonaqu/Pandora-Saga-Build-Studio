# Компактная Книга героя · 0.758.0

## Задача
У навыков текущего героя накопились отдельные видимые примечания, пороги, полный запас ОМ, разбор формулы и несколько вложенных раскрывающихся элементов. Это делает вкладку «Эффекты умений» визуально тяжёлой, хотя расчёты нужны не постоянно.

## Правило показа
- Без раскрытия: оригинальная иконка и RU/EN название из OS, основной числовой результат для текущего героя, базовые ОМ/применение/откат лечения и видимый рассчитанный коэффициент силы физических ударов. Не добавлять вторую карточку для одних и тех же сведений.
- По нажатию **«Подробнее»** в той же строке: рост от уровня, характеристик и зелёного мастерства, количество применений из полного запаса ОМ, пояснение округления, время с «Воодушевлением», базовые затраты боевого умения, требования. Нет второго вложенного переключателя «Как рассчитано» или отдельного раскрытия затрат.
- Расход боевых навыков остаётся отдельной исходной характеристикой, но входит в одно общее раскрытие. Рецепты/связанные игровые действия остаются в Энциклопедии, бонусы союзников — в «Усилениях».
- Значение «—» для неизвестного урона по цели сохраняется; источник 2-секундной модели восстановления, непроверенные серверные сочетания/итоги и стадия округления по-прежнему доступны в подробностях. **Никакие игровые коэффициенты, классификации, D1 и сохранения не изменены.**

## Проверка
Настоящий браузерный сценарий `tests/browser-book-game-terms-664.mjs` проверяет RU/EN, скрытые по умолчанию данные, отсутствие вложенных details, доступность информации после одного клика, исходные базовые ОМ/время и коэффициент удара. Задача #476 продолжается — неизвестные формулы не подменять предположениями.
