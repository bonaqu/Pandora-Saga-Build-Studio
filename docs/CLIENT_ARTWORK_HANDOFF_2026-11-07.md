# Исследование ресурсов клиента OS — результаты и границы доверия

Дата переноса: 7 ноября 2026.

Основание: предоставленный пользователем отчёт `CLIENT_ARTWORK_EXTRACTION_RESULTS_2026-11-06.md` из локального исследования клиента Pandora Saga OS (Codex). Большой архив `Pandora-Saga-Artwork-Research.zip` также передан, но его содержимое **не было повторно разобрано в этой среде** из-за недоступности файлового контейнера. Указанные здесь числа — **результаты из отчёта**, а не новая независимая проверка ZIP.

## Достоверно заявлено в отчёте Codex

- Изучены **34 HED** и **65 DAT**; **63 DAT** индексированы, 2 дополнительно найденных тома не имеют соответствующих записей.
- Всего **32 677 индексных записей**; извлечено **7 288** DDS/TGA, в том числе 6 526 DDS и 762 TGA; CRC32 всех найденных ресурсов проверен при извлечении.
- Подтверждено соответствие именам оригиналов всех **1 173** существующих изображений из манифеста Build Studio; **ни одного точного имени** для **264** отсутствующих оригиналов текущей ревизии не найдено. Вывод ограничен исследованным клиентом/индексами.
- Дополнительно выявлено **529** уникальных имён игровых иконок вне текущего реестра: **516 предметных**, **13 навыковых** (включая `skill_000000000` и 12 имён `940140...`). Это ещё **не доказанные** новые сущности в Build Studio.
- В двух расовых навыках EN и RU имеют разную графическую привязку: `900050003` (Дух энкиду) и `900060003` (Дух кролля). Из 299 клиентских EN/RU пар 297 имели равный RGBA; текущий WebP-архив соответствует EN. Записи идентификаторов **не изменены**, так как это различие локалей, не доказательство ошибки.
- Непроиндексированные тома: `interface_en/0002.dat` (~17,7 МБ) и `interface_ru/0003.dat` (~225 КБ). Не извлекать случайные куски и не подбирать смещения без относящихся к ним индексов/метаданных.

## Работа с полученным ZIP и воспроизводимость

В исходном исследовании, согласно отчёту, есть исходники декодера `scripts/client-artwork/`, разбор HED, потоковое извлечение с CRC/SHA-256, тесты, `gallery.html`, `reports/SUMMARY.json`, `reports/archive-index.json`, `reports/client-matching.json`, `reports/locale-variants.json`, `verified/registry-bindings.json`. Это пути *в исследовательском архиве*, а **не утверждение**, что файлы уже находятся в GitHub.

После восстановления доступа к файлам следует в первую очередь проверить ZIP без исполнения содержимого, список файлов и контрольные суммы, открыть отчёты, повторить детерминированные Python-тесты на безопасных тестовых примерах, затем сверить доказательства для оригиналов. Игровые DLL/EXE не загружать в пользовательский сайт и не публиковать в репозитории.

Состояние живого сайта в версии 0.403.0: для **201** недостающего ID навыка используется **переиспользование** уже сохранённого оригинала *только для оформления*, ещё **59** используют исходную игровую иконку с вопросительным знаком. Манифест продолжает отдельно учёт **264 отсутствующих точных оригиналов**. Никаких восстановленных из клиента файлов этим документом не добавлено.

**Ограничения:** наличие в архиве игровой графики не означает разрешения на публичную перепубликацию; отсутствие имени в текущих индексах не является доказательством отсутствия картинки во всех версиях Pandora Saga.
