## Расчёт и границы
- Обязательно сохранять **зелёное мастерство освоенного корневого навыка**, хотя пакет урона расположен во вложенном действии. Иначе расчёт занижен.
- `P=floor(a*stat/1000)+floor(b*level/1000)+floor(c*greenMastery/1000)+d`; далее согласованные с OS банковское округление INT-фактора, стихийная вариация, подходящие бонусы экипировки/заточки/душ/союзников и штрафы/сопротивления стандартного огра.
- Для `element: NONE/null` OS `Nt()` возвращает PHYSICAL и `_e[0]=30%`; для POISON вариация 0 и сопротивление огра −25%. Использовать ядовитые бонусы только к яду; `EP_ELEMENT_BONUS` только к огню, холоду, молнии.
- **Только один прямой пакет:** не утверждать суммарный урон вращающейся ауры, всех взрывов, возврата ОЗ при Краже жизни, повторных ударов, оглушений, падений, усыплений, отравлений и снижения восстановления. Для «Неотвратимого взрыва» `410004001` отложенный бонус не расшифрован — числового итога нет.
- Любое расхождение корня, дочерней и третьей стадии, их направления, `fv1/fv2`, ID, профессии и требования отменяет расчёт соответствующей строки, остальные навыки продолжают считаться.
