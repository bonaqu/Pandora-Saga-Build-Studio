# Read-only D1 ↔ GitHub snapshot parity — 2026-11-08

Проведена прямая проверка публичных данных GitHub Pages и действующего Worker/D1 (HTTP 200). Это **не** проверка авторизованной записи, миграции или реального игрового клиента.

**Полностью совпали:** 1 116 предметов, 702 монстра, 569 навыков, 112 душ, 187 таблиц добычи монстров, 236 NPC-обменов, 32 сундука, 14 карт, 6 расовых реестров пассивок и вся структура общих игровых таблиц. Порядок полей JSON нормализован при сравнении; полные записи, включая имена, эффекты и связи, сравнивались без частичного семплирования.

**Единственная найденная разница среди 11 игровых ресурсов:** в D1 у шести записей `instances` отсутствует `blurbRu`, присутствующий в GitHub snapshot. Все остальные поля этих записей совпадают. В текущем клиенте уже предусмотрена безопасная подстановка локального `blurbRu`, только если оригинальный `blurb` полностью совпадает; это **не означает**, что D1 уже содержит переводы.

**Действие в production:** пока не вносилось. Для полного перехода D1 в источник RU/EN необходимо принять 6 описаний в проверенную новую версию игрового каталога штатным staged publish, с контролем связей и rollback. Не выполнять неподтверждённые UPDATE существующего активного snapshot.

**Повторяемая проверка:** `npm run catalog:parity:live` сравнивает все 11 JSON с активным D1 snapshot. `npm run catalog:parity:live -- --strict-ru` дополнительно считается ошибкой, пока русские описания отсутствуют в базе. Запросы только GET без токенов и D1-записей.

Метаданные `meta` специально исключены из строгого сравнения: D1-представление содержит curated-сведения, а локальная копия — источник `sha`; одинаковая структура этих двух документов не гарантируется. Рабочие метаданные проверяются отдельной командой `npm run connection:check:full`.
