# Административные выборы Энциклопедии: единые RU/EN подписи (0.486.0)

В редакторе Энциклопедии все общие поля выбора используют уже применяемый на сайте `wt(ru,en)` для интерфейсных слов. Поиск и выбор предмета, классов, эффектов, требований навыков, предыдущих умений и совместимых слотов душ должны отображать один язык без смешивания русских подсказок с английским режимом.

Меняются только надписи поиска, варианты «Выберите…» и доступные имена кнопок (`aria-label`). Игровые названия, связи, ID, содержимое D1 и русские/английские тексты карточек не изменяются. В частности, пользовательские и исходные названия предметов нельзя автоматически переводить по сходству.

Проверки: Node-контракт всех общих селекторов, полный Chromium smoke существующих сценариев энциклопедии и администратора. Сохранение по-прежнему происходит только по явно разрешённым действиям в редакторе.
