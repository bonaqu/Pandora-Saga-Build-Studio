# Pandora Saga Build Studio — implementation roadmap

**Актуальное правило после 0.575.0:** никаких ежедневных или еженедельных GitHub Actions запусков по расписанию. Только проверки при push релиза в `bonaqu_projects` и по ручному запросу. Старые пункты ниже с `daily`/ `schedule` — история прежних релизов, а не действующие инструкции.

**Updated:** 2026-11-17 · **Latest source release:** 0.872.0 (`2026.11.17.872`)

**0.872.0:** GitHub README сокращён до актуальной главной страницы (84 КБ → 3 КБ), вся прежняя версия разложена на небольшие исторические документы с индексом `docs/history/README-ARCHIVE.md`; сокращение не удаляет сведения. **0.869.0:** Общие векторные SVG-иконки выбора/замены, свойств, управления душами, снятия вещи и стрелки перехода вправо (один JS-источник, единое CSS-оформление). ПКМ: «Выбрать другую вещь», «Свойства», «Управление душами», «Снять вещь». Вкладки: «Выбор», «Свойства», «Управление душами». Билингвальные текстовые D1-редакции сохраняют иконки. Node/Chromium регрессии; игровая D1 и формулы не менялись.

**0.868.0:** Стрелка перехода к свойствам предмета теперь использует общий справочник actionIcon() вместо CSS-дубликата. Подпись RU/EN остаётся независимо редактируемой, направление → неизменно; добавлены регрессии Node/Chromium. Сохранения, игровая D1 и формулы не менялись.

**0.867.0:** В образе героя упрощена индикация огненного оружия: загадочная звезда убрана, активное «Пламя феникса» выводится в свойствах только по игровому условию (огонь, заточка +7, доступность). Вкладки «Выбор» ⇄ и «Души» ○ согласованы с контекстным меню. При англоязычном отображении проверяется оригинальный текст источника, а не его перевод. Есть Node + Chromium регрессии; исходный D1-каталог, билды и игровые формулы не менялись.


**0.805.0 (актуальный резерв игрового каталога):** 17 файлов каталога `data/os` синхронизированы с зафиксированным снимком опубликованного D1. Старые 17 JSON сохранены неизменными в историческом тестовом наборе; формулы проверяются по версиям без выдуманных механик. Добавлены SHA-256 gate для побайтового совпадения резерва с кандидатом, контроль ссылок добычи/сундуков/NPC/заточки, учёт новых 20 неподтверждённых оригинальных иконок отдельно от 264 известных 404 без подмен. Существующий Cloudflare D1, библиотека билдов и аккаунты не перезаписываются. После Node + Chromium обязательна read-only приёмка Pages и Worker/D1.

**0.804.0 (редактор сундуков):** Исправлено ограничение размера группы игровых наград: существующий в активном D1 сундук 51036 содержит 127 наград, а админка принимала не более 100. Разрешены до 200 строк с прежними проверками ID, вероятностей, типов призов, количества, душ и золота; не допускается обрезание списка. Новый 45-сундучный снимок проверяется в регрессиях, старый архив и D1 не перезаписываются.

**0.803.0 (Энциклопедия и новый D1):** Источниковые цепочки песен теперь показываются как с исторической формой `EP_STATE_CHANT`, так и с текущим `EP_UNABLE_CAST`, после полной проверки всех связанных эффектов. Новый пассивный навык Загонщика «Увеличение ловушек» 50 ур. получает доступное RU/EN пояснение только для точно известной двухэффектной записи; реальное число ловушек и урон не выдумываются. Статистика Книги героя, D1 и старый архив не меняются.

**0.802.0 (источниковые цепочки Чар):** «Немая буря» и «Чума» снова распознаются в источниковом просмотре на актуальном D1 при точной проверке всех изменённых FV1/FV2 и связанного действия. «Немая буря» показывает новый факт наличия отталкивания без выдуманной вероятности, «Чума» учитывает новое направленное действие вместо старого BOLT. Зависимость от зелёных мастерств, отсутствие автоматического урона и поддержка старого архива сохраняются. D1, аккаунты и резервный архив не изменяются.

**0.801.0 (источниковые эффекты):** В источниковом просмотре улучшенного умения CONJURER «По следам ветра» добавлен отдельный коэффициент «Сопротивление всем стихиям» по второму новому D1-вектору только при точном совпадении FV1/FV2 и времени применения. Значение остаётся предварительной моделью, не становится постоянным сопротивлением или подтверждённым итоговым уроном. Новая «Песчаная буря» проверяется как связанная цепочка 420007101→420007102, без выдуманного урона и вероятностей. Тесты сверяют оба источника и повреждённые версии; D1, аккаунты и резервный архив не изменяются.

**0.800.0 (совместимость с новым D1):** Числовые расчёты на получателе для «Воодушевления» и трёх песен снова распознают строго проверенные новые записи игрового источника; сохраняются старые архивные формы. Верификация включает полные FV1/FV2 и все внутренние стадии; служебное EP_UNABLE_CAST не приравнивается по воздействию к EP_STATE_CHANT, но не блокирует отдельный подтверждённый конечный эффект союзного бафа. Источниковый просмотр «Летящего лезвия» класса CONJURER использует актуальные 2 с / 12 с, однако не выводит неподтверждённый итоговый урон. Новые 420007101/420007102 по-прежнему доступны как данные каталога, без выдуманных боевых чисел. Исходные D1 и архив не меняются; тесты проверяют оба варианта данных и ошибки источника.

**0.799.0 (UX):** В настройке экипировки появились две компактные стрелки для перехода между соседними слотами без закрытия окна; они только открывают подходящий для слота список, ничего не надевая автоматически. В выборе вещей добавлен необязательный фильтр «Доступные на моём уровне» (по умолчанию выключен, чтобы планирование будущей экипировки осталось доступно); состояние фильтра сохраняется при переходе между слотами. В Энциклопедии «← Назад» из прямой статьи на список сохраняет позицию статьи и прокрутку списка в браузерной истории, чтобы пользователь мог вернуться к исходному месту через Back/Forward. Базовые формулы/каталог, D1 и билды не меняются. Пакет включает Node и Chromium регрессии, RU/EN и мобильный компактный стиль.

**0.798.0 (UX):** Библиотека билдов получила компактную сортировку по исходному порядку (по умолчанию), названию, уровню и профессии. Сортировка переставляет только карточки на экране — не меняет порядок хранения, сравнение, поиск или карточки. В таблице очков 1–120 появился быстрый переход к уровню, фильтр изменённых строк и сохранение всех несохранённых значений при просмотре. Фильтры никогда не записывают D1. Уже существующие навигация Энциклопедии и слотный подбор экипировки сохраняются; их отдельная доработка требует подтверждённого пробела при ручном сценарии.

**0.797.0:** Исправлено возвращение логина administrator в поиске «Цель удара» Книги героя: этот модуль использовал собственный конструктор полей и обходил ранее существующую защиту. Добавлен общий поиск `PandoraSearchField`, подключённый до модулей книги и приложения. Он защищает все native input[type=search] в Книге, Пути героя, энциклопедии, экипировке, библиотеке, админке и будущих динамических модулях; Yandex Browser держит неактивный поиск `readOnly` до жеста, не пропуская непрошенное автозаполнение в обработчики. Сохранены редактирование с клавиатуры/касанием, обычная работа Chromium и настоящие поля логина/пароля. Node и Chromium регрессии используют режим UA YaBrowser как моделирование, не гарантируют подавление сторонних браузерных UI-подсказок.

**0.796.0:** Улучшена админка: контекстные подсказки ко всем действиям в панели (RU/EN, наведение/клавиатура), выровнена группировка каталога и очков за уровни, пояснены действия в истории правок, EN и копии GitHub. В редакторе прокачки «Повторить прибавку последнего уровня» заменено на «Заполнить пустые новые уровни» с указанием реальных источника/прибавок/диапазона, отключением без добавленных уровней и сохранением вручную изменённых строк. Заголовки таблицы объясняют разницу между прибавкой и накопленным итогом; кнопки отмены, восстановления и публикации чётко разделены. Новые тесты Node + Chromium проверяют сценарий 55→60 и отсутствие случайной записи в D1. Интерфейс не перегружен новыми карточками.

**0.795.0:** В админке отдельная таблица прибавок очков характеристик/умений от 1-го до максимального уровня. Настраиваемый максимум 55–120, новые уровни без выдуманных начислений, понятные суммы и подсветка изменений. Данные хранятся отдельной D1-записью с CAS и проверкой чтения, не перезаписываются импортом игры. Модели героя и сохранение/открытие билдов поддерживают расширенный диапазон; базовые игровые формулы уровня >55 являются оценкой до подтверждения новой игры. После объединения изменений worker/index.js защищённый workflow автоматически обновляет Worker; до подтверждения новой серверной версии редактор блокирует сохранение.

**0.794.0:** Обновление игрового каталога: игровой предел уровня не ограничивает планировщик 55; перед публикацией проверяются закреплённые бюджеты характеристик/умений 45–55 и базовые ОЗ/ОМ всех профессий/рас. Предпросмотр показывает фактические изменения для текущего героя; неподтверждённые эффекты урона/экипировки не выдумываются. После публикации повторно проверяются таблицы и классы публичной D1 с текущим снимком и расчётами.

**0.783.0:** Учитываются подтверждённые на текущем игровом OS исходнике элементальные эффекты выбранных титулов «Том огня» (+5% только FIRE), «Том бури» (+5% только COLD) и «Том грозы» (+5% только LIGHTNING) в фактическом ударе по Гигантскому огру — в том числе взрыв «Ползучей ловушки». Проверяются все пять векторов выбранного титула, совпадение с числовой моделью Книги и все остальные источники урона в одном финальном алгоритме округления. «Подробнее» показывает итоговую реальную разницу среднего урона от одного титула, без нового блока. Список титулов берёт названия RU/EN из действующего игрового каталога (например, «Том бури», а не историческое «Том льда»), сохранённые индексы не меняются. Документация: [OGRE_HONOR_ELEMENTAL_783.md](../../../docs/OGRE_HONOR_ELEMENTAL_783.md). Следующий приоритет: подтвердить применимость временных расходных и клановых эффектов к конкретному билду по источнику, без предположений о сложении и активации.

**0.782.0:** Глубокая сверка урона «Ползучей ловушки» по Гигантскому огру: Книга героя лениво получает текущую запись монстра 22104 из того же снимка Cloudflare D1, что и билд. Уровень, СД, магическая защита и сопротивления огра больше не остаются неизменными при публикации новых данных. При недоступном/повреждённом снимке результат не выдумывается. В «Подробнее» также показано пробитие огня от предметов и его фактический вклад в средний урон текущего героя; без новых карточек и без рецептов. Контрольная формула и границы точности: [OGRE_DEEP_PARITY_AUDIT_782.md](../../../docs/OGRE_DEEP_PARITY_AUDIT_782.md). Следующий приоритет — подтверждение применимости еды, специальных клановых усилений и титулов к стихийному пакету, без их произвольного сложения.

**0.781.0:** Для Колдуна 45+ в Книге героя можно включить «Сосредоточенность» для следующего прямого стихийного удара по Гигантскому огру. Расчёт на текущий билд учитывает зелёное мастерство, экипировку, души, заточку, союзников и отдельное пробитие огня/холода/молнии. Переключатель встроен в личные усиления, а реальный вклад к среднему удару — в «Подробнее». Рецепты, материалы и общие описания — только в Энциклопедии. Обязательные Node+Chromium перед merge; Pages/Worker/D1 read-only после.

**0.780.0:** Исправлено представление «Ползучей ловушки»: по текущему билду показывается **урон одного взрыва**, потому что в исходниках одно `EP_ELEMENT_DAMAGE`; расход двух предметов `EP_CONSUME_ITEM` нельзя трактовать как два удара. Не показывать выдуманного удвоения; затраты остаются в Энциклопедии. Исправлена пропущенная пассивка «Магические знания»: актуальный OS `940110001` даёт `EP_ELEMENT_DAMAGE_SCALE` +20% для Волшебника, Колдуна и Призывателя от 20 уровня. Добавлена проверка точного эффекта и профессии, новый пересчёт стихийных ударов с уже выбранными вещами/бафами и в том же «Подробнее» числовой вклад пассивки в среднее попадание по огру. ATK/MATK нельзя просто прибавлять к стихийному попаданию: опубликованный OS `Et→kt→Ie→ve→Tt` использует коэффициенты навыка и ИНТ, а физические удары используют другой путь. Без новых карточек и серверных оговорок в интерфейсе. Подробнее: [OGRE_MAGIC_KNOWLEDGE_780.md](../../../docs/OGRE_MAGIC_KNOWLEDGE_780.md).

**0.779.0:** Для всех уже подтверждённых прямых ударов по гигантскому огру раздел «Подробнее» показывает реальную разницу **среднего урона текущего билда** от выбранных союзных усилений, бонусов урона вещей и подходящей магической заточки. Каждая прибавка вычисляется полным исходниковым алгоритмом OS с повторным расчётом без одного конкретного эффекта; никакого суммирования прибавок друг с другом или расчёта недоказанных тиков/серий. Никаких новых карточек, технических оговорок или общих описаний в Книге. «Круг света» и «Неотвратимый взрыв» не получают ложных итогов без подтверждения механики. Подробнее: [OGRE_HIT_GAINS_779.md](../../../docs/OGRE_HIT_GAINS_779.md).

**0.778.0:** Для Снайпера 50-го уровня с луком: «Пламенная стрела / Kindling Arrow» — новый рассчитанный прямой огненный удар по Гигантскому огру из OS Et → kt → Ie → ve → Tt. Учитываются ИНТ, Стрельба, экипировка/магическая заточка и союзные усиления; коэффициент СИЛ здесь 0, так что не рисуем несуществующий прирост. Проверка лука/доступности, русских и английских имён, 2 игровых действий, каста и эффектов. Энциклопедия сохраняет расход боеприпаса и ожог отдельно, без ложного итогового урона. Подробнее: [OGRE_KINDLING_ARROW_778.md](../../../docs/OGRE_KINDLING_ARROW_778.md).
