# Release 0.911.0

## 0.911.0 — 2026.11.19.911 · Диагностика сбоя D1: безопасная проверка схемы и публикации каталога

- После подтверждённого production-инцидента введена автоматическая диагностика только при неудаче release-readiness: удалённый D1 запрашивается по защищённому точному Cloudflare account/database ID, без D1-записи, восстановления снимков и cron.
- Шесть запросов `SELECT`/`PRAGMA` проверяют наличие таблиц, указателя `catalog_current`, строк опубликованного снимка и имена столбцов аккаунтов/сессий. Токены, логины, пароли, билды, каталог и snapshot ID в логи не выводятся.
- Существующий Node-контракт обновлён запретом любых SQL-мутаций в диагностике; обновлён runbook безопасного восстановления D1. Worker 0.361.0 и production D1 не меняются.
- Инцидент с HTTP 503 каталога и HTTP 500 аккаунта подтверждён двумя read-only прогонами после 0.910.0; причина пока не доказана. Никакой возврат к офлайн-архиву не выполняется.
