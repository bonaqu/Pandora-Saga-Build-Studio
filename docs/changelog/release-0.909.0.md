# Release 0.909.0

## 0.909.0 — 2026.11.19.909 · Выбор экипировки без повторной отрисовки и сброса страницы

- «Показать ещё» в выборе предмета теперь добавляет только новые 48 результатов; ранее удалялись и создавались заново все предыдущие 48/96/144 карточек, иконки, hover-превью и обработчики. Поиск и переключение фильтра по уровню по-прежнему пересоздают результаты, поскольку меняется состав списка; названия RU+EN заранее подготовлены для текущего выбора.
- Состояние открытого picker сохраняет поисковую строку, фильтр «Доступные на моём уровне» и количество раскрытых результатов в sessionStorage с ограничением длины/значений. После F5 остаются тот же слот и страницы; новый выбор слота начинает новый поиск.
- При скрытии «Показать ещё» после последней порции клавиатурный фокус передаётся первой вновь открытой карточке и доводится до видимой области. Счётчики показывают фактически отрисованное количество и не становятся D1-контентом.
- Расширены уже имеющиеся Node и реальный Chromium сценарии с source-backed набором оружия воина, проверкой идентичности DOM, полной догрузкой, F5 и фильтрами. Новых тестовых точек входа нет; игровой клиент, Worker и production D1 не изменялись.
