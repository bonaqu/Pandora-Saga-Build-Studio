# Release 0.859.0

## 0.859.0 — 2026.11.17.859 · Улучшена фильтрация полезных предметов в сундуках и размеры карточек гарантированных наград

- Предметы для путешествий, временные сумки, билеты и инструменты теперь можно найти в отдельной категории «Полезные предметы». «Универсальное зелье» отображается среди зелий.
- В разделе гарантированных наград небольшое число карточек сохраняет компактную ширину вместо растягивания на всю строку.
- Фильтрация по слотам экипировки, шансы выпадения, специальные шкатулки за уровень и редактирование наград сохранены без изменений.
- Проверены отображение обычных и специальных сундуков, русский и английский языки, мобильная ширина и сохранность составов наград.
