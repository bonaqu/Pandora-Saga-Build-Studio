# Release 0.961.0

## 0.961.0 — 2026.11.26.961 · Отметили модельность точности и уклонения Remaked; обновили восстановления ОЗ/ОМ от союзников по FV1 OS; проверка API в релизном CI

- Отметили модельность точности и уклонения Remaked; обновили восстановления ОЗ/ОМ от союзников по FV1 OS; проверка API в релизном CI
- `alliedHpPulsePreview` и `alliedNaturalRecoveryPreview` читают исходные FV1 из OS каталога, не из дублированных коэффициентов. Текущие числа сохранены, корректные будущие коэффициенты проигрываются с исходными стадиями Remaked; новые неизвестные зависимости отклоняются.
- Регрессии: сравнение союзных HP/MP пульсов с периодическими моделями жреца, исходные значения, изменённые FV1, нарушения направления/FV2/триггера и правил доступа.
- В Книге героя «Точность» и «Уклонение» показывают маркер «модель» / «model» и RU/EN описание источника; рассчитанные числа и официальные параметры не изменены.
- Актуальный OS API `tables.levelCap:50`; Build Studio по-прежнему планирует до 55. Сверка 17 игровых JSON в релизном CI — только чтение; правки D1 запрещены.
- Node-регрессии 28 профессий × уровни 1–55, доступные подписи, статус результата и безопасное разделение оригинального OS API от Remaked.
