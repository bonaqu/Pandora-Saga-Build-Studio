# Release 0.981.0

## 0.981.0 — 2026.11.27.981 · Проверка 99 связей цепочек умений и защита от подмены дочерних ID

- Для 91 исходной записи закреплены точные 99 ненулевых связей `EP_SKILL_EXEC` с их FV1 и управляющим FV2; подмена целевого ID на другой существующий навык больше не создаёт ложную цепочку.
- Отдельно сохранены легитимные межветочные связи, нестандартные дочерние записи и разветвления. Два нулевых ID не считаются вызовами.
- Параметры работы внутренних эффектов и итоговый урон не выдумываются: цепочки остаются справочными, без изменения боевых статов.
- Проверены 28 профессий × 55 уровней, четыре отдельные on-hit цепочки и 99 подмен связей; D1, авторские правки, Worker, предметы, души и сохранённые билды не изменены.
