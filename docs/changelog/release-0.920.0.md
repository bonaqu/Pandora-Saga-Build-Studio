# Release 0.920.0

## 0.920.0 — 2026.11.19.920 · D1: ранняя проверка snapshot и отмена соседних загрузок

- При ошибке любого из девяти обязательных наборов каталога больше не продолжаются остальные параллельные GET: общий AbortSignal останавливает соседние загрузки и исключает старт новых. Сохраняется первая реальная причина сбоя.
- Отсутствие D1 snapshot и разные snapshot выявляются непосредственно при получении заголовка каждого набора, до разбора очередных крупных JSON и публикации в редакторе.
- Публичный GET теперь подчиняется AbortSignal и таймауту даже при зависшем стороннем HTTP-адаптере. Аналогично отменяется зависший разбор кода исчерпанной квоты; устаревший ответ не создаёт ложный cooldown.
- Расширены существующие Node-тесты: зависший fetch, таймаут, поздний ответ quota, групповой abort и порядок результатов. Полный Chromium и Node обязательны на HEAD PR. Без изменений формул, аккаунтов, D1-схемы, слотов, переводов или пользовательских билдов.
