# Release 0.882.0

## 0.882.0 — 2026.11.18.882 · Устойчивый запуск после F5: повторы временных GET-сбоев и ограничение параллельных D1-запросов

- Защищён публичный запуск при серии обновлений F5: GET к D1 и статическому файлу перевода повторяются не больше трёх раз только при временных сетевых ошибках, HTTP 408/429/500/502/503/504 с небольшими паузами.
- Девять основных наборов данных и двенадцать наборов Энциклопедии загружаются ограниченными группами по три, уменьшая одновременную нагрузку на сеть и Worker.
- Проверки единого снимка и признака источника D1, полноты данных, RU/EN и localStorage остаются строгими. Ошибки авторизации, повреждённый JSON или неправильные D1-заголовки никогда не считаются сетевым успехом.
- Chromium воспроизводит многократный F5, временные 429/5xx/отказ сети, постоянную недоступность Worker, автоматическое восстановление без F5 и сохранность черновика без POST в D1. Node проверяет границы повторных запросов.
