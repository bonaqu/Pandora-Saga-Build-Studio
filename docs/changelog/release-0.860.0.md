# Release 0.860.0

## 0.860.0 — 2026.11.17.860 · Три коротких сообщения профиля получили настраиваемые RU/EN-подписи без изменения авторизации

- «Код скопирован», «Скопируйте выделенный код» и «Резервный код скрыт.» теперь имеют отдельные RU/EN-подписи, доступные для редактирования владельцем по месту.
- Сырые ответы сервера, пароли, резервные коды и имена пользователей не становятся редактируемыми; подсказки не перезаписывают форму входа и сохраняют существующую проверку конфликтов.
- Node и Chromium тестируют разделение редакторского текста и ответов сервера, подтверждение сохранения резервного кода и отсутствие админских элементов у обычного посетителя.
