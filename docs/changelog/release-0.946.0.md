# Release 0.946.0

## 0.946.0 — 2026.11.20.946 · Прямое редактирование без карандашей у обычного текста

- Режим владельца: авторский текст снова редактируется непосредственно двойным кликом, без дублирующего значка ✎ рядом с каждой надписью. Карандаш остаётся только для реальных отдельных подсказок при наведении.
- Удалены лишние кнопки из общего редактора RU/EN, Происхождения, профиля, Пути героя, книги героя, выбора экипировки/душ, энциклопедии и вспомогательных панелей администратора. Текст, числовые значения игры и подсказки хранятся/редактируются независимо.
- Действия кнопок и навигация различают одиночный и двойной клик в режиме владельца; предусмотрен F2 без декоративных кнопок. Серверные CAS, Undo, рабочие билды, формулы и производственные данные D1 не изменены. Остаточный аудит по #390 остаётся открытым.
- Редактор проверки игрового каталога тоже приведён к общей модели: пояснения, предупреждения, чекбоксы и названия действий правятся прямо по тексту, включая недоступные до проверки кнопки. ✎ остался только у отдельных hover-подсказок. Отдельно проверяются сохранение через D1 и отсутствие запуска сравнения/публикации от двойного клика.
