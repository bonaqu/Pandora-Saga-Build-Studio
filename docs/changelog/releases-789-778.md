## 0.788.0 — 2026.11.14.788 · Урон в доле ОЗ цели и раздельные сопротивления

- Книга героя → «Эффекты умений»: для каждого уже проверенного одиночного попадания показывается **доля полного запаса ОЗ выбранного монстра**, которую составляет текущий средний удар. Полные ОЗ берутся из того же источника D1, что и сопротивления и уровень, без дополнительной загрузки. Примерный шанс победы, число ударов до победы, повторные удары и вероятность попадания не выдумываются. Отображается одна компактная RU/EN строка в прежнем раскрытии навыка.
- Общая строка «Сопротивления цели» теперь **разделена на самостоятельное влияние сопротивления конкретной стихии и общего магического сопротивления**. Для каждого результата полностью повторяется тот же проверенный OS-расчёт с обнулением ровно одного фактора, с сохранением пробития, предметов, союзных усилений и округлений. Их нельзя складывать в одну сумму. Прежний совокупный показатель оставлен внутри модели для регрессий, не дублируется игроку.
- **Живые D1-данные:** смена монстра или изменение его полных ОЗ сразу обновляет процент; урон от удара не меняется только из-за роста запаса здоровья противника. Некорректные поля не подменяются фиксированным огром. Для пары исходников «Круга света» и «Неотвратимого взрыва» по-прежнему нет доказательств серверного порядка/задержек; полная сумма урона не придумывается.
- Новый `tests/os-monster-hp-resistances-788.test.mjs` сверяет каждый компонент по четырём монстрам и разным школам с независимым повторным OS-расчётом, проверяет пробитие, отрицательные/нечётные сопротивления, полный запас ОЗ и порченые записи D1. Расширенный `tests/browser-book-monsters-785.mjs` проверяет RU/EN интерфейс и смену цели; подробности в `docs/BOOK_TARGET_LIFE_RESISTANCES_788.md`.

- Интерфейс остаётся компактным: одна текстовая строка в существующем раскрытии навыка, RU/EN. Новые карточки, рецепты, материалы и преждевременные «полные результаты» для «Неотвратимого взрыва» и «Круга света» не создавались.

Детали в `docs/BOOK_NEXT_HIT_GAINS_787.md`. Обязательные Node+Chromium до слияния, Pages/Worker/D1 только на чтение после.
