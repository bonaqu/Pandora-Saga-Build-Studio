# Release 0.904.0

## 0.904.0 — 2026.11.18.904 · Доступные RU/EN-подписи фильтров Энциклопедии

- Четыре семейства фильтров Энциклопедии используют общую модель подписей и D1-CAS: 14 вариантов вида экипировки, 2 выбора совместимости героя, 7 стихий, 7 категорий предметов эффектов и пять доступных названий селекторов (всего 35 новых редактируемых подписей); существующий редактор категорий навыков не продублирован.
- В режиме владельца эти опции редактируются в одном сворачиваемом разделе на самой странице. В обычном режиме нет панелей или карандашей редактора. Длинный список прокручивается внутри, не раздувая страницу.
- Для каждой опции сохраняются стабильный внутренний ID фильтра и RU/EN-текст отдельно; D1-подписи не меняют сортировку, выбор экипировки, условия совместимости или предметы. Сохранение, Undo, конфликты CAS и смена языка используют текущие механизмы без отдельной таблицы или новой панели.
- Дополнены существующие Node/Chromium регрессии на исходные ID, RU/EN D1-запись, фильтрацию, выбор категории и условные элементы. Игровые формулы, Worker и production D1 не изменены.
