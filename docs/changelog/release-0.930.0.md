# Release 0.930.0

## 0.930.0 — 2026.11.19.930 · Энциклопедия сундуков: 35 D1 RU/EN-подписей

- Одна компактная панель владельца объединяет 35 двуязычных подписей открытия сундука, пустых записей, наград, групп, шансов и количества, фильтров и действий владельца. Применяется действующий inline D1 CAS/Undo без новых модалок.
- Выделены статические подписи и не изменяемые пользователем числовые суммы: ID, исходные предметы, шансы, количество и последовательность розыгрышей не входят в D1-текст. Переход между фильтрами заново подставляет актуальные подписи, не старые локальные строки.
- Связанные существующие Node и Chromium сценарии расширены проверками D1-ключей и отсутствия редакторских контролов у гостей. Ни Worker, ни формулы, ни production D1 не изменены.
