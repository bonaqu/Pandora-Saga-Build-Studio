# Release 0.955.0

## 0.955.0 — 2026.11.26.955 · Архивная сверка перенесена в дополнительные инструменты; поиск билдов очищается одной кнопкой на ПК и телефоне

- Архивная сверка перенесена в дополнительные инструменты; поиск билдов очищается одной кнопкой на ПК и телефоне
- Архивное сравнение остаётся доступно по желанию; текущая игра — основной вариант сверки.
- RU/EN, автосохранение, CAS, билды и D1 не меняются. Браузерная проверка и публикация подтверждаются отдельно.
