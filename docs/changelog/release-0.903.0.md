# Release 0.903.0

## 0.903.0 — 2026.11.18.903 · Обновление без ложного режима редактора

- Разделены причины блокировки релиза: активный режим владельца, незавершённая D1-запись, D1-подключение, открытые формы и предупреждения аккаунта. Неактивный администратор с сохранённой авторизацией больше не получает текст «выйди из редактора»; сохранение имеет собственный RU/EN-текст и стабильный D1-ключ.
- Баннер актуализирует причину при изменении состояния редактора/очереди записи и после проверки версии, без принудительного закрытия окна, потерянных правок или лишнего обновления DOM.
- Расширены существующие Node и Chromium-тесты: гость без единого входа в редактор, завершённый режим с сохранённым токеном, ожидающие D1-CAS записи, ручное и автоматическое обновление и безопасный переход с cache-bust URL.
- Worker, игровые каталоги, расчёты и production D1 не изменены; клиент игры не использовался.
