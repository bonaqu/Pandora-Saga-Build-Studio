# Release 0.959.0

## 0.959.0 — 2026.11.26.959 · В Образе героя выровняли иконки и подписи пустых слотов по центру на ПК и телефоне

- В Образе героя выровняли иконки и подписи пустых слотов по центру на ПК и телефоне.
- Пустые слоты: иконка и подпись центрируются вместе; выделение и размеры рамки не сдвигают контент.
- Полная браузерная проверка геометрии при 390, 1366, 1920, 2560 и 3840 px; надетые предметы, души, заточка и доступность слотов остаются без изменений.
- D1, CAS, Worker, формулы, игровые записи и сохранённые билды не изменены.
