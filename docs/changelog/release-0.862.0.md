# Release 0.862.0

## 0.862.0 — 2026.11.17.862 · Редактируемые RU/EN названия категорий и типов экипировки в сундуках

- В разделе обычных сундуков 12 категорий наград и 13 типов экипировки получили отдельные RU/EN-подписи, которые владелец может менять прямо в свёрнутых блоках через существующий D1-CAS редактор.
- Изменяется только интерфейсный текст: значения категорий и слотов, подсчитанное число наград, игровые ID и шансы остаются неизменными; у гостя редактор отсутствует.
- Node/Chromium проверяют безопасные настройки, исходные каталоговые данные и прежнее поведение фильтрации.
- Browser acceptance and deployed Pages state must be verified separately.
