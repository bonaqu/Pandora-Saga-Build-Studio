# История релизов · 0.858.0—0.840.0

## 0.858.0 — 2026.11.17.858 · Стабильная ширина карточек наград сундуков в неполной последней строке

- **PR #690:** исправлена компоновка при фильтрации наград обычных сундуков: CSS Grid с `auto-fill` сохраняет одинаковую ширину карточек во всех строках, включая неполный последний ряд «Шкатулки древнего короля».

## 0.857.0 — 2026.11.17.857 · Доступные слоты сундуков видны сразу, а отфильтрованные награды компактны

- **PR #688:** выбор оружия, брони, шлемов, поясов, колец и остальных реально присутствующих слотов доступен сразу под «Все награды». Нажатие слота включает подходящий фильтр одним действием; название и количество наград рассчитаны из опубликованного каталога.
- После фильтрации каждый источник розыгрыша показывает видимое и исходное число вариантов, а карточки имеют компактную сетку без растягивания одной награды на весь блок. Шансы, порядок, редактор и D1 неизменны.
- Шкатулки за уровни сохраняют прежний интерфейс. Node и Chromium проверки изменений успешно прошли на PR #688; реальная публикация Pages проверяется отдельно.
- **#683:** семь уровней предметов остаются 55 в публичном D1 на момент контрольного read-only запроса; требуется штатное администраторское CAS-обновление до 50, а не публикация резервных файлов GitHub.

## 0.856.0 — 2026.11.17.856 · Фильтры обычных сундуков по типу награды и слоту экипировки, с сохранением специальных шкатулок за уровень

- **#685:** в Энциклопедии обычные сундуки получили фильтр наград по фактическому типу предмета: экипировка с 12 слотами, зелья, бальзамы и усиления, самоцветы, души, материалы, вложенные сундуки, золото и прочее.
- Категории автоматически вычисляются из опубликованных `kind`/`slot` и связей; новые неизвестные предметы безопасно попадают в «Прочее». Фильтр не меняет вероятности, количество, группы, исходные индексы редактора и D1.
- Все 32 специальные шкатулки за уровни 5–60 (включая победителя) сохраняют прежний интерфейс. Для сундуков без известного содержимого фильтр не показывается.
- Node проверяет все текущие источниковые розыгрыши и будущие неизвестные виды; Chromium проверяет крупные сундуки, экипировку по слотам, души, золото, RU/EN, 390px и сохранность специальных шкатулок.
- **D1:** у семи игровых предметов из #683 в последней read-only проверке опубликованного D1 всё ещё было `level=55`, а в официальном источнике и резервном каталоге `level=50`; релиз GitHub Pages не публикует игровые данные в D1, для этого требуется штатная авторизованная CAS-синхронизация.
- Проверки Node+Chromium и фактическое развертывание Pages/Worker подтверждаются раздельно.
