# Release 0.935.0

## 0.935.0 — 2026.11.19.935 · Редактор локаций: защита от потери изменений списков, лимиты тегов и разделов, RU/EN-поля и корректный гостевой режим

- Списки тегов, разделов, NPC и добычи перед сохранением сверяются с актуальной версией D1-карточки: устаревшая форма не перезаписывает новые изменения.
- Для тегов показан лимит в 16 записей, дубликаты отклоняются до записи, кнопка блокируется до завершения запроса; 14 новых RU/EN-текстов подключены к действующему D1-редактору.
- Пустые авторские текстовые секции не подсказывают гостям недоступное редактирование; при лимите 12 разделов владелец видит понятное объяснение.
- Дополнены существующие Node/Chromium тесты: stale-list, ограничения, корректность данных и живое редактирование подписей на карте.
