# Release 0.922.0

## 0.922.0 — 2026.11.19.922 · D1: отмена устаревших Wiki-пакетов и фоновых проверок

- При изменении опубликованного каталога или авторских D1-правок Энциклопедия прекращает старую группу запросов. Новая загрузка не ждёт устаревших GET и повторно проверяет единый snapshot.
- Ограниченный публичный загрузчик принимает внешний AbortSignal; внутреннее прерывание соседних запросов при сетевом отказе, три одновременных набора и сохранение первоначальной ошибки не ослаблены. Отмена никогда не превращается в публичный архивный fallback.
- D1 heartbeat прерывается при offline и скрытии вкладки, а при возвращении выполняется свежая проверка; поздний ответ не может разблокировать либо ложно заблокировать редактор. Скрытый focus не делает сетевых GET.
- Добавлены реальные асинхронные регрессии в существующие Node-наборы: отмена трёх активных запросов, pre-abort, отсутствие локального fallback и поздний checkpoint. Обязательны полный Node/Chromium CI и post-merge read-only приёмка. Worker, D1-схема, игровые формулы и пользовательские билды не менялись.
