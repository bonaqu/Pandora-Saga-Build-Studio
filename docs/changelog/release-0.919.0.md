# Release 0.919.0

## 0.919.0 — 2026.11.19.919 · Сетевой checkpoint: отмена устаревших запросов и фоновых опросов

- Повторные публичные D1 GET прекращаются немедленно при отмене запроса во время HTTP 429/503 и сетевого backoff. Для штатного ожидания освобождается таймер; пользовательские задержки в тестовых адаптерах также не могут удерживать отменённый запрос.
- Проверка обязательного D1-snapshot повторно учитывает AbortSignal после обоих HTTP-ответов и разбора JSON. Даже fetch/JSON-адаптер, проигнорировавший отмену, не разблокирует устаревшие игровые данные.
- Опрос новой версии Pages прекращён в скрытых вкладках; при уходе вкладки отменяется активный запрос, а при возврате выполняется новая проверка. Поздний ответ скрытой вкладки не показывает баннер новой версии.
- Расширены существующие Node-регрессии: остановка повторных GET после отмены, поздний D1 checkpoint, фоновые проверки версии и отказ от устаревшего баннера. Игровые формулы, аккаунты, D1-схема и production-записи не изменены. Полные Node/Chromium CI и опубликованный сайт проверяются отдельно.
