# Release 0.899.0

## 0.899.0 — 2026.11.18.899 · Ссылки на билды без гонок запросов и потери контекста

- **Публикация ссылки:** несколько быстрых нажатий «Поделиться» на одной карточке больше не создают параллельные POST/GET, не расходуют повторно серверный лимит и не подменяют новое уведомление устаревшим ответом.
- **Изоляция аккаунтов:** начальный токен и владелец библиотеки закрепляются на весь POST→GET. При logout/смене пользователя ответ старого запроса не отправляет подтверждение под новым токеном, не рисует ссылку/ошибку в чужой карточке и не разрешает копировать старую ссылку из прежнего интерфейса.
- **Точный снимок:** сравнение ответного снимка выполняется с неизменяемой копией сохранённого героя на момент клика. Внутренние изменения билда во время запроса не приводят к ложному отклонению; реально несовпадающий ответ по-прежнему отклоняется. Успех показывается только после GET-подтверждения.
- **Обработка сбоев:** блокировка повторного клика снимается в finally и не застревает после ошибок; уничтоженная карточка никогда не получает запоздалый результат. Локализованный контент и режим D1-редактирования подписи остаются на месте.
- В существующие Node и Chromium-сценарии добавлены исполняемые проверки задержанного POST/GET, смены владельца, отсоединённой карточки, корректного readback и повторной попытки. Production D1 и игровые данные не изменялись.
