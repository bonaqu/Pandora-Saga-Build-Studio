# Release 0.906.0

## 0.906.0 — 2026.11.19.906 · Безопасный поиск и D1-подпись прогресса душ

- В Яндекс Браузере синтетические keydown/pointerdown больше не снимают защиту поискового поля. Доверенные события вставки, перетаскивания, диктовки, удаления и Undo распознаются при фокусе; автозаполнение логином по-прежнему отбрасывается.
- В списке совместимых душ текст «Душ» / «Souls» получил стабильный RU/EN D1-ключ и компактный карандаш владельца. Числа текущей страницы и общего результата существуют независимо от редактируемой подписи; дозагрузка не пересоздаёт её.
- Расширены существующие Node/Chromium тесты синтетических событий, RU/EN, чисел, жизни DOM при пагинации и доступа владельца. Игровые формулы, каталог, Worker и production D1 не менялись.
- Browser acceptance and deployed Pages state must be verified separately.
