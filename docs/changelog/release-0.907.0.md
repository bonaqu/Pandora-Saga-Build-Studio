# Release 0.907.0

## 0.907.0 — 2026.11.19.907 · Общая защита числовых полей и поиска от автозаполнения

- Один проверяемый Yandex guard защищает все неавторизационные поля типа search/number: случайная или программная подмена значения, а также синтетические input/change не вызывают сохранения неверной характеристики, уровня или поиска. При фокусе и безопасных пользовательских жестах сохраняются реальные значения.
- Ввод клавиатурой, мышью, тачем, вставка, удаление, IME/диктовка и undo/redo используют одинаковую проверку доверенного события. Поля логина/пароля не затронуты; блокировка браузерного всплывающего менеджера паролей не гарантируется.
- Удалены две разошедшиеся реализации Yandex-наблюдателей. Штатные обновления через +/−, пересчёты характеристик, числовой owner-редактор и замер Энциклопедии теперь явно синхронизируют значения без разблокировки посторонних событий. Node/Chromium регрессии дополнены; новых тестовых entrypoints нет. D1, Worker и формулы не менялись.
- Browser acceptance and deployed Pages state must be verified separately.
