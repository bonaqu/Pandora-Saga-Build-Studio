# Release 0.975.0

## 0.975.0 — 2026.11.27.975 · Три самоусиления в Книге героя используют общие коэффициенты OS вместо зафиксированных +100/+30

- Три самоусиления в Книге героя используют общие коэффициенты OS вместо зафиксированных +100/+30: Ускользание, Лёгкость и Стремительная стрела берут выводимую величину из той же full-source проверки, что применяет их к текущему герою.
- В RU/EN больше нет неподтверждённого процента для интервала выстрела или старого числа после обновления OS; неподдерживаемые FV/класс/оружие скрывают числовой результат.
- Полная регрессия модельных величин и ненадёжных исходных копий; Worker/D1/CAS, игровые файлы и сохранения не менялись.
