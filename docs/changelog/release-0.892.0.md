# Release 0.892.0

## 0.892.0 — 2026.11.18.892 · Надёжные статусы редактора и компактные обновления UI

- Ожидающие RU/EN D1-записи учтены единообразно: статус сохранения, Undo, EN-переводы и «Завершить» используют общую проверку; промежуточное состояние очереди не отображается как окончательно сохранённое.
- Сохранение/Undo обновляет лишь изменившиеся пользовательские надписи и ARIA: Энциклопедия, экипировка, Origin, библиотека, панель редактора. Неизменённые элементы и активные поля не пересоздаются.
- Ручное и автоматическое обновление сайта теперь одинаково защищает активные `plaintext-only` поля, включая фокус внутри них.
- Существующие Node/Chromium сценарии расширены проверкой очереди, активного редактирования и идемпотентности DOM. Worker, игровая модель и production D1 не менялись.
