# Release 0.861.0

## 0.861.0 — 2026.11.17.861 · Праздничные предметы сундуков и настраиваемая RU/EN-подпись фильтра экипировки

- В сундуке «Ритуальная утварь» девять подтверждённых праздничных предметов получили самостоятельную категорию RU/EN вместо общего «Прочее». Неизвестные будущие предметы и шкатулки за уровень не переименовываются.
- Подпись «Тип экипировки» теперь редактируется владельцем на месте через существующую CAS-защиту D1; карандаш скрыт от обычных посетителей.
- Проверка Node и реальный Chromium охватывают содержимое сундуков, фильтрацию, неизменность шансов и приватность редактора; игровой клиент не требуется.
- Browser acceptance and deployed Pages state must be verified separately.
