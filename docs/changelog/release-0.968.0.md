# Release 0.968.0

## 0.968.0 — 2026.11.27.968 · Пять личных усилений используют текущие FV1 OS вместо зашитых коэффициентов Remaked

- Пять личных усилений используют текущие FV1 OS вместо зашитых коэффициентов Remaked.
- Хладнокровие и Быстрое уклонение берут плоский, статовый и мастерский коэффициенты из текущих FV1; Ускользание, Лёгкость и Стремительная стрела берут числовой индекс из текущего OS-каталога.
- Для нескольких эффектов сохраняются разные проверяемые каналы, а неизвестные FV2, дополнительные EP и изменённые условия потери эффекта блокируют модель.
- Сохранены существующие модельные стадии Math.floor Remaked; они не являются подтверждённым серверным PvP-расчётом.
- Обязательные Node / Chromium, затем Pages + Worker/D1 read-only без изменения пользовательских сохранений, D1, CAS и данных игры.
