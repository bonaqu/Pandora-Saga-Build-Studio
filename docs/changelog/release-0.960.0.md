# Release 0.960.0

## 0.960.0 — 2026.11.26.960 · Модели лечения читают актуальные коэффициенты умений OS; подсказки силы заклинаний показывают «модель»

- Модели лечения читают актуальные коэффициенты умений OS; подсказки силы заклинаний показывают «модель».
- `healingSpellsPreview` и `periodicRecoveryPreview` берут FV1 непосредственно из опубликованного OS каталога, не из устаревающих литералов. Корневой Sanctuary строго ссылается на дочерний эффект лечения.
- Текущие числа остались прежними, при новых валидных коэффициентах модель пересчитывается; некорректные FV1/FV2/ID отвергаются.
- Новые Node регрессии: 28 классов × 55 уровней, смена исходных коэффициентов, два языка и отрицательные сценарии. Браузерный CI и live readiness проверяются перед публикацией.
- Значения и формулы D1/Worker/сохранений не меняются; точные серверные округления вне подтверждения.
