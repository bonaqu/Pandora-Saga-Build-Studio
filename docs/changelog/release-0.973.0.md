# Release 0.973.0

## 0.973.0 — 2026.11.27.973 · Безболезненность читает снижение атаки из OS и проверяет все пять эффектов

- Безболезненность читает снижение атаки из OS и проверяет все пять эффектов: числовая величина теперь из текущего `EP_DAMAGERATE_SCALE`, а не зашита как -50%.
- Одновременно строго проверяются пять исходных TARGET-эффектов, класс и групповое мастерство MELEE, требования 100 и отсутствие непроверенных FV2.
- Расчёт результата и порядок округления остаются моделью Remaked; баф не применяется к герою автоматически, D1/Worker/CAS/билды не затронуты.
