# Книга героя — итоговые показатели без формул в UI

Эталон представления: [Pandora Saga Simulator Remaked Modern UI, `modern/adapter.js`](https://github.com/bonaqu/Pandora-Saga-Simulator-remaked/blob/bonaqu_projects/modern/adapter.js). `readCalculatedSummary()` считывает готовые значения `Status_*` и возвращает итог, без публичного раскрытия коэффициентов.

Build Studio: `PandoraStageAttributes.summaryRows()` получает вычисленные результаты из `PandoraOSCalculator.base()`. В главах «Атака» и «Защита» показаны компактные итоговые показатели. Неизвестные величины показываются как «—», не как ноль. Расчёты, условия, округления и проверки остаются в движке и тестах, но не превращаются в публичные уравнения или повторные таблицы. На вкладке «Усиления» остаются настройки.

Условные эффекты оружия, вещи и души, которые ещё нельзя корректно суммировать с общим параметром, можно показывать отдельно во вкладке «Эффекты», не подменяя ими итоговые характеристики. Ядовитый корень (50022) и ядовитое зелье (50056) остаются только в Энциклопедии → Предметы эффектов → Дают отрицательные эффекты. Использование вызывает временное отравление с периодическим уроном ядом по использовавшему предмет персонажу. Числовое значение `EP_DESTINED_POISON.a = 50` нельзя выдавать за величину тика, интервал, шанс или длительность без проверенного правила сервера.

При смене экипировки, навыков, усилений и локали интерфейс заново показывает конечные результаты. RU/EN перевод не меняет арифметику.
