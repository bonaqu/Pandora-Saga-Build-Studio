# 0.971.0 · Source-first MELEE Despair and three-channel Enchantment

The live `pandorasaga-os.com/gamedata/skills.json` source exposes separate EP coefficients; the final hit, buff stacking and packet rounding are still **Remaked-model** assumptions. These UI previews do not mutate a hero build, server or D1.

- `100058001` **Отчаянье / Despair**: official source skill has `branchRaw=MELEE`, `branch=martial`, and exactly three TARGET effects: `EP_DAMAGERATE_SCALE` with `FV1=[0,0,35,40]`; `EP_ONDAMAGE_FIN_DAMAGE_SCALE=[0,0,0,100]` (received-damage side effect); `EP_LOST_ATK_END=[0,0,0,0]` (termination). The old formula incorrectly depended on green Slash alone, even though `martial` is a zero-cap pseudo-branch. The preview now uses the **sum of trained green Slash, Thrust, Brush, Blow, Defense**, the same existing MELEE group source gate as other skills: `40 + floor((sum of five green branches) * 35/100)`. The displayed ATK addition remains a **model**; equipment, combo and damage-reduction rules are not inferred.
- `320011001` **Чары усиления / Enchantment**: three separate TARGET `EP_AURADAMAGE_SCALE [20,0,20,10]`, `EP_AURADAMAGE_CONST [5,0,10,5]`, `EP_ELEMENT_DAMAGE_SCALE [0,0,20,10]`. The three source parameters are read dynamically from each exact `fv1` vector and are displayed as `coefficient-model`, never as final damage or a permanent additive hero stat. Example with SPI=80 and trained Blessing=50: `36, 14, 20`, modeling separate coefficient roles. An unknown FV1 role, FV2 field, wrong direction, additional EP, incorrect caster class or unknown component fails closed.

Both full-root gates preserve access requirements (class, level, prerequisite chain, mastery caps). Shifts in supported coefficient channels update the model from current OS source; other shifts hide the speculative output. Tests: `tests/os-melee-despair-enchantment-source-971.test.mjs`, 28-class exclusion and synthetic vector mutations; full Node/Chromium PR CI and post-merge Pages/read-only Worker/D1 required. No user-build migration or source-catalog/D1 edits.

**Evidence boundary:** OS exports the coefficients, Remaked supplies the *candidate* stage of arithmetic; no new claim of live-client rounding or actual applied damage. Issue #476 remains open.
