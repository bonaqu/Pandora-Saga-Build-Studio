# 0.980.0 — два стрелковых навыка и полная проверка каналов дальности

**Граница доказательства:** экспортированные FV1/FV2 подтверждают исходные численные параметры. Расчёт коэффициентов по мастерству и итоговой прибавки к АТК в текущем Build Studio сохраняет статус **модели**, не измеренной серверной формулы урона/попадания.

| ID | Навык | Разрешённые каналы коэффициентов | Полностью проверяемые контрольные операции |
|---|---|---|---|
| 213605001 | Точная стрельба (SNIPER, ур. 45) | `EP_DAMAGERATE_SCALE`, `EP_TOHIT_CONST` FV1[2/3]; `EP_ATTACKRANGE_CONST` и `EP_ATTACKCARRY_CONST` FV1[2/3] | `EP_UNABLE_MOVE`, `EP_TOGGLE` с подписанным FV2, все FV2 остальных операций |
| 213703001 | Двойной выстрел (PREDATOR, ур. 50) | `EP_ATTACKRANGE_CONST` и `EP_ATTACKCARRY_CONST` FV1[2/3] | `EP_DOUBLE_MISSILE` (включая его отрицательное FV1[3]) и все FV2 |

У каждой записи проверяются ID, профессия, уровень, исходная ветка, требование оружия, последовательность действий и отсутствие неизвестных полей. Допустимое изменение диапазона FV сохраняет общий источник, но требует **равенства двух полных векторов** RANGE и CARRY. Добавить оба значения к дальности нельзя: показана только одна модельная прибавка при действующем навыке. Пара `CARRY` является отдельным каналом, не второй суммой.

Текущая исходная величина для «Точной стрельбы» при 65 мастерства: `200 + floor(65×300/100)=395`; при согласованном увеличении обоих FV1[3] на 20 получается 415. Для «Двойного выстрела» при 55 мастерства: `100 + floor(55×900/100)=595`. Эти числа — модель от исходного вектора, не конечная дистанция попадания. При изменении атаку и точность «Точной стрельбы» не смешивают; изменение лишь второго канала не увеличивает АТК.

Новое неизвестное состояние переключателя, действие попадания, дополнительный EP, нарушенная зеркальность, дробный/отрицательный неподдерживаемый FV или чужая профессия полностью запрещают числовую модель. Не подтверждены точные шансы срабатывания, числовые стадии попадания и серверные округления.

Проверка:

```bash
node --test tests/os-range-source-fv-980.test.mjs tests/os-skill-attack-range-721.test.mjs
npm run release:check
npm test
```
