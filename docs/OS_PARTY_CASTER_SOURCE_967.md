# 0.967.0 · Союзные усиления: совпадение исходных прав и коэффициентов OS

## Проверенный текущий источник

Все шесть навыков читаются из `data/os/skills.json`, прямо сопоставленного с официальными файлами `https://pandorasaga-os.com/gamedata/skills.json`. Для каждого корня нужно подтвердить не только `FV1/FV2` и `EP_*`, но и его роль в игровом каталоге: исходные профессии применяющего, ветвь, уровень, требования, `learnable:true` и отсутствие предшествующего умения.

| ID | Название | Источник-профессии | Уровень / ветвь |
|---|---|---|---|
| 320001001 | Боевой клич | GLADIATOR, JUGGERNAUT, DRAGOON | 28 / martial |
| 100055001 | Массовая сосредоточенность | AGENT, ASSASSIN, DISTURBANCE | 28 / archery |
| 260006001 | Помощь ветра | ASCETIC, MONK, EXORCIST | 28 / exorcism |
| 320004001 | Благословение ветра | ARCHER, SNIPER, PREDATOR | 28 / archery |
| 330004001 | Божественное благословление | KNIGHT, GENERAL, PALADIN | 28 / martial |
| 320002001 | Благословенный покой | PRIEST, CLERIC, ENCHANTER | 20 / blessing |

При корректном источнике значения `fv1[3]` **остаются динамическими** и подставляются в те же *модельные* ступени Remaked, что и прежде. Получатель не обязан быть одной из перечисленных профессий: источник относится к применяющему союзнику. Если сама исходная структура изменилась (профессии, класс, ветвь, требования, уровень, предшествующее умение), система **не выдумывает** сохранение старого эффекта и отказывается от числа до новой проверки.

Сводка `PandoraOSCalculator.alliedRecipientPreviews` и фактически выбираемые `PandoraRemakedBuffs.applied/choices` должны согласованно отклонять изменённую структуру. Общие правила доступности остальных исходных союзных корней также не должны принимать `learnable:false`, некорректные требования и отсутствие профессий.

Проверка: `tests/os-party-caster-source-proof-967.test.mjs`, 48 отрицательных мутаций исходников шести умений + 1540 сценариев 28 классов × 55 уровней, плюс обязательные Node/Chromium и read-only проверка Pages/Worker/D1.

Итоговые серверные стаки, вероятность срабатывания, PvP-уменьшение урона и независимый источник игрового округления **не подтверждены**; расчётные модели не повышены до verified. Изменений SQL/D1/CAS/профилей/сохранений нет. #476 остаётся открытой.
