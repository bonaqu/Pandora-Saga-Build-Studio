# Редактор сундуков и большой список наград

15 ноября 2026 опубликованный D1 содержит 33 обычных сундука и 12 NPC-сундуков. У предмета 51036 «Шкатулка древнего короля» 127 отдельных результатов в одной группе. Ранее редактор разрешал максимум 100 и отклонял весь корректный набор.

Проверено по сохранённому D1-снимку `ps-ca9a604163b54a2da5c83ea55077ef96`. Старый архив `data/os` не изменён. Для публикации обязательны Node, Chromium и проверка версии; это не доказательство реальных вероятностей выпадения.
