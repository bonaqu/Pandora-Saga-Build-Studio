# Приёмка обновления резервного каталога · 15 ноября 2026

**Релиз 0.805.0 · production D1 не изменяется.**

Рабочий резерв `data/os` содержит все 17 JSON D1-снимка `ps-ca9a604163b54a2da5c83ea55077ef96`. Каждый JSON побайтно и по SHA-256 сверяется с закреплённым кандидатом. Этот снимок опубликован в активном D1 владельцем ранее; перенос в резерв не вызывает write, publish или CAS для D1.

Сохранены все 6 авторских русских описаний подземелий. 20 новых оригиналов иконок имеют честное `Not attempted`, 264 старых источника — отдельно подтверждённые `HTTP 404`; случайная подмена запрещена.

Проверки: полный Node, Chromium, локальный read-only gate каталога, реальный WebP-аудит, release guard. После объединения — GitHub Pages (version 0.805.0), Worker/D1/CORS и сравнение 16 активных наборов с новым `data/os` только HTTP GET. Не объявлять проверку окончательно завершённой до такого read-back. Работающий интерфейс не раскрывает пользователям сайт, из которого взяты данные.
