# 0.809.0: фоновая очередь резервирования каталога (#615)

Активный снимок D1 и резервное задание GitHub PR записываются в одну транзакцию. Cloudflare Worker Cron каждые пять минут повторяет задания независимо от браузера. Сбой сети вызывает повтор с экспоненциальной задержкой; смена D1 snapshot отменяет устаревшее задание; конфликт чужой ветки фиксируется как требующий внимания. Токен GitHub не покидает Worker.

Owner-only initialize создаёт добавочную таблицу; CI и деплой не выполняют миграций. Автоматический merge по-прежнему требует Node и Chromium на точном SHA с актуальным D1 snapshot. Эта работа не доказывает семантику неизвестных боевых эффектов (#615 остаётся открытой).
