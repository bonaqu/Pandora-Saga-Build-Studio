# 0.965.0 · Союзные «Воодушевление» и «Вольный ветер» из текущего OS

Источники: действующий `pandorasaga-os.com/gamedata/skills.json`, совпадающий с локальным `data/os/skills.json`, и исторический UI Remaked `js/calc.js`.

- `320006001` **Воодушевление**: `EP_SKILL_DELAY_FIN`, `fv1=[0,0,0,50]` (текущий официальный срез). До сих пор клиент использовал фиксированное `50`. Теперь берётся подтверждённое значение `fv1[3]` с ограничением `1..100` при строго нулевых первых трёх ячейках и `fv2`. Модели: `castTimePercent=x`, `castTimeReductionPercent=100-x`, `speedMultiplier=100/x`. Серверные стадии/зависимости времени остаются **не подтверждены**; это расчёт Remaked, вход `x` взят из текущего OS.
- `260010001` **Вольный ветер**: `EP_MOVESPEED_SCALE`, `fv1=[0,0,0,200]`; отдельный нулевой `EP_LOST_MAPCHANGE`. Теперь бонус берётся из `fv1[3]` с диапазоном `0..1000` вместо фиксированных `200`; отмена при смене карты и проверка ограничения СНАЙПЕРА Warding 66/90 остаются.
- Оба эффекта по-прежнему требуют точных ID, класса/цели и исходной структуры. Новая зависимость от характеристики, уровня, мастерства, `fv2`, неожиданный знак/диапазон или отсутствие отмены карты **не превращаются** в число.
- Отдельные эффекты активируются только с выбором пользователя; изменение каталога не включает их автоматически и не меняет локальные билды/D1/Worker.

Регрессии: `tests/os-allied-inspiration-freewind-fv-965.test.mjs`, 351 отдельное числовое значение, 1540 контекстных комбинаций 28 профессий × 55 уровней для инвариантов исходника, негативные изменения каждого FV-канала и направлений. Два пользовательских числовых результата остаются *source-backed modeled*; это не подтверждение скрытой скорости анимации, временных ограничений или серверного порядка округления.

Все изменения проходят обязательные Node/Chromium и после merge — Pages/Worker/D1 read-only.
