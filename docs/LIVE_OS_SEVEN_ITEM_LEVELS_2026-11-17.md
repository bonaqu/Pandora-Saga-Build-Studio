# Проверка уровня предметов по опубликованному OS API — 17.11.2026

В рамках read-only сверки `https://pandorasaga-os.com/gamedata/items.json`
(HTTP 200, JSON) и сохранённого `data/os/items.json` найдены
**ровно семь отличий неописательных полей**. Все семь относятся к
`level`; в текущем опубликованном источнике требуется 50 уровень
вместо старого 55. Общее количество предметов не изменилось: **1140**.

| ID | Предмет | Было в архиве | В текущем API |
|---:|---|---:|---:|
| 19010 | Магическое кольцо | 55 | 50 |
| 19011 | Кольцо поединка | 55 | 50 |
| 20027 | Священные четки | 55 | 50 |
| 20028 | Ожерелье войны | 55 | 50 |
| 21019 | Пояс пророка | 55 | 50 |
| 21020 | Пояс души | 55 | 50 |
| 22022 | Украшение тишины | 55 | 50 |

Исходные JSON-записи не заменялись целиком. Изменены **только семь
числовых `level`**; прежние описания, ID, иконки, свойства,
классовая совместимость, заточки и души сохранены. Опубликованный
текст описаний нормализован иначе (среди отличий много пропавших
`<br>`); это не основание для изменения формул или разрушения
читаемого форматирования. Все **571 навыков** при той же read-only
сверке совпали с сохранённым `skills.json` при структурном сравнении
разобранных JSON-записей (571 из 571).

Регрессии проверяют доступность семи предметов на уровне 50,
блокировку на уровне 49, неизменный лимит планирования 55,
неприкосновенность остальных игровых параметров и 1140 source ID.

Это обновление **встроенного резервного источника**, а не запись в
production Cloudflare D1. Если в D1 отдельно ещё сохранён устаревший
уровень, публикация через админку остаётся самостоятельной
условной CAS-операцией. Никаких игровых тестов и автоматического
перезаписывания пользовательских билдов.
