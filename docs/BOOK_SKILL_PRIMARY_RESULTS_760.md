# 0.760.0 · Показатели умений и ближайшие приросты в Книге героя

## Для игрока
Когда доступный навык текущего билда имеет один вычисленный показатель силы удара или силы заклинания, **это число показано прямо возле названия**, без большого прочерка и повторной строки «Эффект». При нескольких разных эффектам остаётся одна компактная строка со всеми значениями; никаких новых разделов не появляется.

В прежнем **«Подробнее»** доступен ближайший порог зелёного мастерства, на котором сила удара увеличится на +1% по текущему вектору OS. Для шести уже поддержанных стихийных заклинаний отдельно показаны следующие +1 к коэффициенту силы от ИНТ и от мастерства. Учтены округления и пределы текущего класса. Например, «Критический удар», Рубящий 40: сила удара +20%; следующий +1% при Рубящем 42. При Рубящем 41 значение остаётся +20%. Для «Двойного удара» при Секущем 70 новый рост не обещается, поскольку на Секущем 71 его заменяет «Порез».

## Границы механик (не выводить игроку в виде служебных оговорок)
- Новые поля `nextMastery` / `nextStat` возвращаются только когда текущий навык доступен; значения рассчитываются из уже проверенного вектора коэффициента, без чтения сети и без изменения записей.
- `EP_ONHIT_DAMAGE_SCALE` (кастер) — коэффициент от текущего мастерства; это НЕ число попаданий/урон по конкретной цели. `EP_ELEMENT_DAMAGE` — вычисленный компонент заклинания, а не окончательный урон после сопротивления цели.
- Калькулятор не начисляет навыки, союзные бафы или экипировку автоматически. Показатели мастерства берутся из текущего персонажа; недоступные ветви и заменённые ранги не получают фиктивных порогов.
- Повторное описание усилений союзников удалено: раздел уже указывает контекст. Геймплейные значения и возможность самостоятельно включать союзные усиления не меняются.
