# 0.979.0 — два личных эффекта: динамические коэффициенты и контроль полной записи

**Область:** только read-only «Эффекты умений» в Книге героя. Итоговый серверный урон/вероятность действия навыка **не доказаны**. Значения из экспортируемого каталога подтверждают исходные коэффициенты, но не способ их применения игровым движком.

| ID | Умение | Текущие FV1 | Применяемая модель | Побочная операция |
|---|---|---|---|---|
| 260005001 | Быстрое уклонение | `[5,0,15,10]` | `10 + floor(AGI * 5/100) + floor(Warding * 15/100)` | Нет |
| 142051001 | Хладнокровие | `[0,0,20,10]` | `10 + floor(Cleaving * 20/100)` | `EP_LOST_CHANGE_WEAPON` |

Параметры `AGI`/`Warding`/`Cleaving` берутся из текущего героя и его распределения навыков. Стадии `floor` сохранены из существующей модели, а не объявлены доказанными серверными операциями.

## Почему изменена проверка

Прежняя модель требовала точного равенства основного вектора со старыми числами, поэтому допустимая правка текущего каталога выключала целиком расчёт. Кроме того, для `142051001` не контролировался второй эффект `EP_LOST_CHANGE_WEAPON`; при его изменении модель продолжала показывать критическую прибавку без полной информации о её действии.

Теперь обе записи проходят проверку `MYSELF`, принадлежности ветке, способа изучения, уровневых ограничений, классов, требований мастерства, вида оружия, количества и направления операций, FV1/FV2 и побочных действий. Поддерживаемые диапазоны существующих коэффициентов допускают автоматическое обновление величины. При изменении типа действия, дополнительного вектора или появления неизвестного эффектa модель **не показывается**, вместо того чтобы придумывать результат. Изменение допустимого FV1 сохраняет `modelOnly:true` и `uncertain:true`.

## Проверка

```bash
node --test tests/os-personal-coefficient-source-fv-979.test.mjs
npm run release:check
npm test
```

Тесты включают стандартные 19 уклонения и 24 крит. шанса при прежних параметрах, изменение каждого разрешённого канала FV1, отклонение новых FV2/EP, подмены условий, обрыв `EP_LOST_CHANGE_WEAPON`, запрет чужого оружия, 28 профессий и наличие ограничений обучения. Тестовые варианты не записываются ни в D1, ни в сохранения.
