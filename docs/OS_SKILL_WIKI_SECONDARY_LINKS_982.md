# 0.982.0 — связанные действия в энциклопедии

Пять переходов от изучаемых умений к другим игровым записям теперь отображаются в разделе навыков энциклопедии. У четырёх из них переходы ранее не выводились, хотя оба конца цепочки уже проверялись по полным исходным сигнатурам. Пятый переход, «Озарение», продолжает выводиться через общий просмотрщик без повторения.

| Основное умение | ID | Связанная запись | Подтверждённое обозначение действия |
|---|---:|---:|---|
| Удар по щиту | 142503001 | 142503002 | EP_ATTACK_BLOCK_BREAK |
| Контратака | 161202001 | 161202050 | EP_SKILL_PARRY_COUNTER |
| Летящее лезвие | 420005001 | 420005004 | EP_SKILL_EXEC_DIFFUSION |
| Улучшенное Летящее лезвие | 420005002 | 420005003 | EP_SKILL_EXEC_DIFFUSION |
| Озарение (существующая цепочка) | 420001002 | 420001003 | EP_SKILL_EXEC |

Справочные переходы формируются только если уже существующий просмотрщик `combatTechniquePreview` / `specializedSkillPreview` подтвердил **полную сигнатуру** и корневого умения, и дочерней записи, а действие действительно указывает на ожидаемый ID. Подмена ID на *другой реально существующий* навык, изменение эффектов дочерней записи или нарушение классовых условий отключают новые ссылки; никакая общая формула не подставляется.

**Граница доказательства:** связь между двумя ID и исходное направление действия подтверждены игровыми данными. Это **не подтверждает** итоговый урон, шанс срабатывания парирования или сбивания щита, успешность попадания, число поражённых целей и временные интервалы. Поля остаются `sourceOnly:true`, `finalAmount:null`, `appliedToHero:false`. Справочник показывает навигацию, а не новый постоянный стат героя. Числа каталога, D1, Cloudflare Worker и сохранённые билды не изменялись.
