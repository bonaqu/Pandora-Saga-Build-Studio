## Что исправлено в 0.772

Основной калькулятор (`pandora-os-character-calculator.js`, `forthSnapshotAtGrade`) применяет последний уже достигнутый накопительный эффект улучшения предмета. Предыдущий независимый калькулятор урона по цели выбирал только точную запись для указанного `grade`, отчего при редких таблицах пропадал расчёт: например, у **Золотистой астирской куртки** (`12605`) `itemForth` хранит ступени только +2/+4/+6/+8/+10. На +3 действует +1%, на +5 — +2%. Теперь применяются эти значения, и контрольное сравнение с `combat.spellDamageEquipmentRate` не отклоняет корректный билд.

Три эффекта Ползучей ловушки полностью сверяются по ID, направлению и всем `fv1/fv2`: `EP_CONSUME_ITEM → EP_SKILL_EXEC → EP_SKILL_EXEC → EP_ELEMENT_DAMAGE`. Ошибочно изменённый исходник не порождает фальшивый результат. Предположения о числе срабатываний, задержке детонации и DPS НЕ добавляются.

Дополнительно: души используются только при совместимости с ячейкой и текущим предметом; диапазоны `min/max` эффекта учитывают степень улучшения. У комплектов не считать корневой предмет или повторяющиеся ID за дополнительные части. Огненный кинжал зноя (`1862`) получает свои +1% к огню на +7 и +2% на +8 только при соответствующем выборе стихии.

## Контрольные примеры по Ogre

Это **математические контрольные билды**, не чьи-либо сохранённые герои. Загонщик уровня 45, ЛВК 70, ИНТ 20, зелёное мастерство Ловушки 41: без экипировки 34/148/194 ОЗ; с курткой +3 при неизменном ИНТ для изоляции бонуса заточки — 35/150/196 ОЗ; с курткой +5 — 35/152/198 ОЗ. В реальном интерфейсе бонус +1 ИНТ самой куртки также учитывается основной моделью характеристик, поэтому итог текущего полностью экипированного героя может отличаться от изолированного теста.

В Книге героя остаётся одна компактная строка доступного навыка; под «Подробнее» — средний урон, влияющие характеристики и ненулевые бонусы выбранного героя. Рецепты, ингредиенты, связи и общий текст остаются в Энциклопедии.
