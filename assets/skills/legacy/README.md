# Historical Pandora Saga simulator branch symbols

These PNG images are copied from `bonaqu/Pandora-Saga-Simulator-remaked/image/icon` and used only as **branch-level decorative symbols**, not exact live skill icons. A missing historical `23-00` is not fabricated. The separate `scripts/mirror-os-icons.mjs` downloads actual OS item/skill/soul icons into their own categorized folders and emits a manifest for the site after manual execution and review.
