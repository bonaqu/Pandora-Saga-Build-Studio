# Pandora Saga Build Studio — CHANGELOG

## 0.931.0 — 2026.11.19.931 · Энциклопедия предметов: 29 двуязычных подписей через D1

- В карточку предмета добавлена одна компактная owner-панель с 29 статическими RU/EN-подписями источников, материалов, связей с умениями, шансовых действий и редактирования эффектов; сохранение использует существующий D1 CAS/Undo.
- Игровые характеристики, ID, список эффектов, рецепты и динамические количества не редактируются через тексты. «Показать ещё» использует D1-подпись только для предметов, не меняя таблицу душ.
- Убраны остававшиеся русские подписи цели эффекта, поиска и пустых вариантов в EN-редакторе; лимит 32 эффекта имеет отдельный английский текст.
- Действующие Node и Chromium сценарии расширены RU/EN контрактами, сохранением подписи через мокированный CAS, проверкой данных и отсутствия owner-редактора у гостей. Без production D1 writes, Worker и изменений формул.

## 0.930.0 — 2026.11.19.930 · Энциклопедия сундуков: 35 D1 RU/EN-подписей

- Одна компактная панель владельца объединяет 35 двуязычных подписей открытия сундука, пустых записей, наград, групп, шансов и количества, фильтров и действий владельца. Применяется действующий inline D1 CAS/Undo без новых модалок.
- Выделены статические подписи и не изменяемые пользователем числовые суммы: ID, исходные предметы, шансы, количество и последовательность розыгрышей не входят в D1-текст. Переход между фильтрами заново подставляет актуальные подписи, не старые локальные строки.
- Связанные существующие Node и Chromium сценарии расширены проверками D1-ключей и отсутствия редакторских контролов у гостей. Ни Worker, ни формулы, ни production D1 не изменены.

## 0.929.0 — 2026.11.19.929 · Надёжный жизненный цикл подсказок и сенсорное управление

- Подсказки подключаются к каждому DOM-элементу один раз; повторные RU/EN/D1-обновления заменяют текст и задержку без дублирующих обработчиков событий и наблюдателей.
- При очистке авторского текста отменяется ожидание, закрывается открытая подсказка и возвращается исходный tabindex. Восстановление текста не создаёт новых слушателей.
- На сенсорных экранах подсказка обычной подписи остаётся после синтетического click и закрывается вторым касанием, нажатием снаружи, Escape или навигацией; кнопки и ссылки не теряют действие.
- Расширены существующие тесты жизненного цикла: повторное подключение, задержка, D1-копия, очистка, ARIA и touch. Без D1-записей, изменений игровых формул или Worker.

## 0.928.0 — 2026.11.19.928 · Единый RU/EN поиск и навигация по локациям Чести

- Общий SearchField теперь предоставляет `normalize`, `compile` и `matches` с Unicode NFKC, ё/е, регистронезависимым поиском и свободным порядком слов. Имена и идентификаторы игрового D1 не меняются.
- Мастерская, библиотека билдов, Энциклопедия, Путь героя, поиск душ и раздел «Честь» используют одно правило вместо разрозненных копий нормализации. Компилируемый предикат повторно используется внутри поиска по статье и при подборе локации.
- В выборе существующих локаций «Чести» совпадение работает с русским и английским названием, словами в произвольном порядке и ё/е. Отсев уже добавленных локаций использует Set вместо повторного поиска по всему списку.
- Действующие Node-тесты и браузерный Honor smoke дополнены проверками реального механизма поиска и обратного порядка слов. Формулы, каталог, счета, Worker и production D1 не изменялись.

## 0.927.0 — 2026.11.19.927 · Ограниченная сетевая загрузка аккаунта, билдов и D1 CAS

- Вход, регистрация, восстановление доступа и проверка аккаунта ограничены единым AbortSignal-deadline при получении HTTP-заголовков и чтении JSON. Зависший ответ не превращается в успешный вход и не удаляет текущую сессию; мутирующие POST-запросы не повторяются автоматически.
- Облачная библиотека аккаунта ограничивает те же два этапа GET/POST. При потере ответа библиотека не выдаёт ложного подтверждения сохранения и не переадресует чужие билды.
- Административные D1 CAS операции и read-only API имеют общий предел ожидания, включая чтение тела. На не подтверждённую/оборванную запись ставится ошибка, счётчик незавершённых операций уменьшается, поздний JSON не становится «Сохранено». Старые ожидаемые значения CAS не подменяются.
- Регрессии добавлены в существующие Node test modules: зависания headers и JSON в аккаунте, библиотеке и CAS, отсутствие повторной отправки, сохранение состояния при позднем подтверждении. Формулы, игровой каталог, Worker, D1 schema и production D1 не менялись.

## 0.926.0 — 2026.11.19.926 · D1 checkpoint не зависает при чтении JSON; надёжнее read-only приёмка

- При запуске редактора девять обязательных наборов D1 теперь ограничены по времени как на этапе получения ответа, так и при чтении тела JSON. Поздний успех отменённого запроса не изменяет героя и не разблокирует устаревшую версию.
- Тот же общий `PandoraStudioOnlineGate.untilAbort` защищает параллельные проверки опубликованного каталога и RU/EN overrides при переподключении, включая адаптеры, игнорирующие `AbortSignal`. Источник D1, версия snapshot и содержимое по-прежнему обязательны.
- Read-only приёмка account-only Worker делает не более трёх GET при транспортном сбое или таймауте; возвращённые HTTP 403/405/500 не превращаются в разрешённый 401 и не маскируются повторными запросами. Это реагирование на подтверждённый таймаут 0.925.
- Новые функциональные Node-проверки в существующих файлах: зависшие fetch/JSON для обоих D1 endpoint, явная отмена, ограниченная диагностика Worker. Игровые данные, формулы, Worker/D1 схема, учётные записи и production D1 не менялись.

## 0.925.0 — 2026.11.19.925 · Ограничено ожидание D1-загрузки Wiki и добавлена CSS-приёмка адаптива

- Загрузка Энциклопедии теперь прерывает зависшие fetch-адаптеры и чтение JSON даже если адаптер не выполняет AbortSignal. Истёкший таймаут не разрешает старые D1-данные и не включает публичный архивный fallback.
- Необязательное локальное RU-описание подземелья ограничено тем же таймаутом и не удерживает уже проверенный D1-каталог. Тесты покрывают зависшие заголовки/JSON обеих ветвей.
- CI различает quick, layout и full: CSS-пакеты проверяют действующий desktop/mobile UI и отдельные layout-скриншоты, без всей тяжёлой матрицы; runtime/Worker/каталог остаются на полном Chromium.
- Полный Node и обязательный Chromium принимаются по точному SHA PR; Pages/Worker/D1 проверяются отдельно и только чтением. Игровые данные, формулы, аккаунты и production D1 не изменялись.

## 0.924.0 — 2026.11.19.924 · Энциклопедия переиспользует проверенный D1 snapshot героя

- После успешной загрузки Мастерской уже проверенные D1-наборы `meta`, `items`, `skills`, `souls`, `racialPassives` и `tables` больше не скачиваются повторно при первом открытии Энциклопедии. Запрашиваются только шесть отсутствующих наборов: монстры, локации, подземелья, добыча, обмены NPC и сундуки.
- Переиспользование возможно только для каталога с подтверждённым текущим D1 snapshot и структурной валидацией. Каждый новый GET обязан иметь исходный заголовок D1 и ту же версию. При несовпадении или неполном источнике — отказ вместо архивного fallback. Сохраняется полная финальная проверка связей Wiki.
- Начальный герой, редактирование, RU/EN, account-only библиотека и игровые формулы не меняются. Редакторские overrides продолжают пересобирать локальный индекс без повторных массовых загрузок. Это экономит ровно шесть браузерных запросов к каталогу при типовом входе; экономия запросов непосредственно к SQL D1 не измерялась.
- Дополнены существующие Node-тесты согласованного seed/mismatch/отказа до сети и опубликованный Chromium-сценарий с реальным переходом в Wiki и подсчётом запросов. Полные Node + Chromium и read-only проверка Pages/Worker/D1 обязательны.

## 0.923.0 — 2026.11.19.923 · Путь героя: 11 редактируемых RU/EN-подсказок с D1 CAS/Undo

- Пояснения вложенных очков, зелёного мастерства, заблокированной расовой ветки, общей шкалы и исходных очков получили общие семантические ключи book.path.*. Игровая логика осталась неизменной; редактируется только текст помощи.
- Подписи навигации и ссылок на предыдущие/следующие навыки, а также пояснение дальности от оружия используют те же D1-ключи. Имена навыков и числовые значения являются отдельными неизменяемыми фрагментами.
- Для владельца один сворачиваемый раздел «Подсказки Пути героя» использует общий inline D1 CAS/409/Undo; игроки не видят админских элементов. Изменение подписи обновляет data-help, aria-label и текст уже созданного элемента без сброса поиска и прокачки. RU/EN-переключение не удаляет открытый редактор.
- Расширены существующие Node-тесты ключей и неизменности игровых имён, а также Chromium-сценарий владельца с RU/EN CAS. Без изменений Worker, D1-схемы, формул и игровых ресурсов.

## 0.922.0 — 2026.11.19.922 · D1: отмена устаревших Wiki-пакетов и фоновых проверок

- При изменении опубликованного каталога или авторских D1-правок Энциклопедия прекращает старую группу запросов. Новая загрузка не ждёт устаревших GET и повторно проверяет единый snapshot.
- Ограниченный публичный загрузчик принимает внешний AbortSignal; внутреннее прерывание соседних запросов при сетевом отказе, три одновременных набора и сохранение первоначальной ошибки не ослаблены. Отмена никогда не превращается в публичный архивный fallback.
- D1 heartbeat прерывается при offline и скрытии вкладки, а при возвращении выполняется свежая проверка; поздний ответ не может разблокировать либо ложно заблокировать редактор. Скрытый focus не делает сетевых GET.
- Добавлены реальные асинхронные регрессии в существующие Node-наборы: отмена трёх активных запросов, pre-abort, отсутствие локального fallback и поздний checkpoint. Обязательны полный Node/Chromium CI и post-merge read-only приёмка. Worker, D1-схема, игровые формулы и пользовательские билды не менялись.

## 0.921.0 — 2026.11.19.921 · Энциклопедия: D1 пакет с ранней проверкой snapshot и общей отменой

- Общий лимит в три параллельных запроса Энциклопедии теперь использует сигнал отмены всей пачки: при недоступном, неподтверждённом или повреждённом наборе оставшиеся загрузки прекращаются, следующие не отправляются.
- D1-происхождение, отсутствие snapshot и расхождение версий проверяются сразу по заголовку каждого из 12 обязательных наборов, до загрузки остальных JSON; итоговая строгая проверка каталога остаётся обязательной.
- Локальные тестовые fixture и исторические языковые описания сохраняют прежние ограничения; публичный архивный fallback не разрешается. Игровые данные, формулы, записи D1, авторские overrides и сохранённые билды не изменялись.
- Регрессии добавлены к существующим Node-наборам, включая реальную общую отмену и раннее выявление split-snapshot. Полный Node/Chromium CI и финальная проверка production D1 только на чтение обязательны.

## 0.920.0 — 2026.11.19.920 · D1: ранняя проверка snapshot и отмена соседних загрузок

- При ошибке любого из девяти обязательных наборов каталога больше не продолжаются остальные параллельные GET: общий AbortSignal останавливает соседние загрузки и исключает старт новых. Сохраняется первая реальная причина сбоя.
- Отсутствие D1 snapshot и разные snapshot выявляются непосредственно при получении заголовка каждого набора, до разбора очередных крупных JSON и публикации в редакторе.
- Публичный GET теперь подчиняется AbortSignal и таймауту даже при зависшем стороннем HTTP-адаптере. Аналогично отменяется зависший разбор кода исчерпанной квоты; устаревший ответ не создаёт ложный cooldown.
- Расширены существующие Node-тесты: зависший fetch, таймаут, поздний ответ quota, групповой abort и порядок результатов. Полный Chromium и Node обязательны на HEAD PR. Без изменений формул, аккаунтов, D1-схемы, слотов, переводов или пользовательских билдов.
