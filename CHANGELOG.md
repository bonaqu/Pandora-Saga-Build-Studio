# Pandora Saga Build Studio — CHANGELOG

## 0.874.0 — 2026.11.17.874 · Редактируемые D1-подписи и чистый интерфейс игрока

- Новые пояснения о вместимости слотов душ редактируются через D1; рядом есть компактный карандаш только в подтверждённом режиме редактора.
- Индикатор редактора отсутствует в начальной HTML-разметке, создаётся только для авторизованного владельца и удаляется после выхода.
- Энциклопедия показывает игровые сведения о неопределённой добыче вместо формулировок «добавлено редактором»; три подписи получили D1-ключи RU/EN.
- Упрощён текст профиля и сообщения обычных запросов без раскрытия технических деталей; серверные инструменты для владельца сохранены.
- Эта правка не требует записи в production D1: исходные подписи работают без overrides, новые значения пишутся в D1 исключительно после сохранения владельцем.


## 0.873.0 — 2026.11.17.873 · Вкладка душ при 0 слотах и компактный ROADMAP

- В оружии, щите, шлеме, броне, перчатках, штанах, обуви и поясе вкладка «Управление душами» остаётся доступной для просмотра при 0 слотах. Вместо пустого списка показывается краткое объяснение RU/EN с типом вещи; неизвестная вместимость не выдаётся за ноль.
- Разрешения на реальную установку душ, контроль совместимости и ограничения вместимости не изменены. Другие типы экипировки сохраняют две вкладки.
- Исторический ROADMAP сохранён целиком и разбит на 20 небольших архивных файлов с индексом. В корневом ROADMAP остались действующие ориентиры, связи с задачами и проверки; старые исторические TODO не выдаются за текущие.
- Изменены только UI, тесты и документация. Нет записи в D1, изменения формул, игрового JSON, Worker или сохранений.


## 0.872.0 — 2026.11.17.872 · Компактный README и точная компоновка экипировки

- Главная страница GitHub больше не показывает устаревшие списки релизов: README сокращён примерно до 3 КБ, предыдущий текст полностью сохранён в шести небольших архивных документах с индексом.
- В строке свойств «Выбор» визуально отдельно; при наличии душ вкладке управления выделено больше пространства, при отсутствии душ кнопки «Выбор» и «Свойства» занимают равные половины без разросшегося блока свойств.
- Внутренняя прокрутка карточки предмета получила более спокойное оформление, боковая полоса без тяжёлого тёмного фона; сохранены клавиатура, редактирование D1-подписей, компактная высота и RU/EN.
- Игровые значения, Cloudflare D1, Worker, аккаунты, сохранения и формулы не изменялись.


## 0.871.0 — 2026.11.17.871 · Интерфейс экипировки и компактный архив истории

## 0.869.0 — 2026.11.17.869 · Чёткие SVG-иконки и логичный порядок действий экипировки

- Проверки Node/Chromium на одинаковые иконки, порядок, клавиатуру и переключение языков; игровые данные и Cloudflare D1 не изменены.

## 0.868.0 — 2026.11.17.868 · Единый источник иконок экипировки: стрелка перехода к свойствам без отдельного CSS-символа

- GitHub Actions, Pages, Worker и D1 приёмка проверяются независимо; публикация не изменяет игровые каталоги, билды и D1.
