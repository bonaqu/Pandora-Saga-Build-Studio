# Pandora Saga Build Studio — CHANGELOG

## 0.913.0 — 2026.11.19.913 · Оптимизация чтений D1: кэш по снимку, атомарная защита публикации и проверка Worker

- Публичный Worker читает D1-указатель актуального снимка **при каждом** запросе каталога, а повторные большие ответы по тому же снимку и набору берёт из Cloudflare Cache API с TTL 60 секунд. Ключ содержит версию опубликованного каталога, а не данные пользователя; кешируются только HTTP 200 с `x-ps-catalog: d1` и совпадающим `x-ps-catalog-snapshot`.
- При ошибке указателя D1 сайт получает HTTP 503 без старого кэша/архива. Смена снимка немедленно меняет ключ. При сбое Cache API чтение продолжается напрямую из D1, без потери работоспособности.
- Админский `/api/admin/catalog/batch` отклоняет записи в опубликованный снимок (HTTP 409). Предикат `NOT EXISTS` встроен в сам SQLite INSERT/UPSERT и предотвращает гонку между подготовкой пакета и публикацией. UI продолжает создавать новый случайный снимок для обновления каталога.
- Runtime capabilities и workflow деплоя подтверждают новый snapshot cache при публикации Worker. Расширены существующие Node-тесты: кэш-хит, смена снимка, испорченный кэш, недоступность D1, атомарная гонка и валидный staging; остальной Node/Chromium CI обязателен. Production D1 не изменяли через административные операции, игровой клиент не проверялся.

## 0.912.0 — 2026.11.19.912 · D1: диагностика суточных лимитов и стоимости запросов, сокращение лишних CI-запусков

- При неудаче production readiness D1 теперь распознаются точные Cloudflare-сообщения о суточном лимите чтений и записей, ошибках схемы, перегрузке или недоступности; добавлен дешёвый `SELECT 1` для разделения ошибок SQL и метаданных. Ошибки и SQL целиком не логируются.
- Скрипт также пытается получить read-only `wrangler d1 insights` за последние сутки, выводит только категорию запроса и агрегаты rowsRead/rowsWritten/executions. Отсутствие Account Analytics Read не маскирует исходную ошибку; D1-записей и раскрытия пользовательских данных нет.
- GitHub Actions `workflow_run` отфильтрован по ветке ещё до старта workflow: каталогный авто-merge работает только для `catalog/snapshot-ps-*`, зеркалирование оригинальных иконок — только для `bonaqu_projects`. Вторичная проверка ветки внутри jobs сохранена, обязательные Node/Chromium не отключены.
- Расширены существующие контрактные тесты и эксплуатационный runbook. Подозрение на D1 Free row-read cap остаётся гипотезой до прямого подтверждения; никаких откатов Time Travel или архивного режима.

## 0.911.0 — 2026.11.19.911 · Диагностика сбоя D1: безопасная проверка схемы и публикации каталога

- После подтверждённого production-инцидента введена автоматическая диагностика только при неудаче release-readiness: удалённый D1 запрашивается по защищённому точному Cloudflare account/database ID, без D1-записи, восстановления снимков и cron.
- Шесть запросов `SELECT`/`PRAGMA` проверяют наличие таблиц, указателя `catalog_current`, строк опубликованного снимка и имена столбцов аккаунтов/сессий. Токены, логины, пароли, билды, каталог и snapshot ID в логи не выводятся.
- Существующий Node-контракт обновлён запретом любых SQL-мутаций в диагностике; обновлён runbook безопасного восстановления D1. Worker 0.361.0 и production D1 не меняются.
- Инцидент с HTTP 503 каталога и HTTP 500 аккаунта подтверждён двумя read-only прогонами после 0.910.0; причина пока не доказана. Никакой возврат к офлайн-архиву не выполняется.

## 0.910.0 — 2026.11.19.910 · Аккаунт: сохранение курсора и формы при RU/EN, безопасное завершение D1-редактирования

- Переключение RU/EN в профиле сохраняет активное поле, положение курсора и выделения, прокрутку, раскрытие изменения пароля и введённые значения. Перерисовка не отправляет форму и не раскрывает приватный ввод в хранилище.
- Если во время перевода открыт редактор авторского текста с D1 CAS/Undo, перерисовка профиля откладывается до закрытия редактора вместо потери несохранённого ввода. Повторные переключения не создают конкурирующие обновления.
- Статус сохранения резервного кода больше не превращается в обычное сообщение: редакторский ключ остаётся после переключения RU/EN; серверные ошибки и секреты по-прежнему не редактируются.
- Расширен действующий реальный Chromium-сценарий аккаунта: RU/EN, курсор, приватный ввод, незавершённый редактор и статус восстановления. Игровые формулы, Worker, production D1 не менялись.
- Browser acceptance and deployed Pages state must be verified separately.

## 0.909.0 — 2026.11.19.909 · Выбор экипировки без повторной отрисовки и сброса страницы

- «Показать ещё» в выборе предмета теперь добавляет только новые 48 результатов; ранее удалялись и создавались заново все предыдущие 48/96/144 карточек, иконки, hover-превью и обработчики. Поиск и переключение фильтра по уровню по-прежнему пересоздают результаты, поскольку меняется состав списка; названия RU+EN заранее подготовлены для текущего выбора.
- Состояние открытого picker сохраняет поисковую строку, фильтр «Доступные на моём уровне» и количество раскрытых результатов в sessionStorage с ограничением длины/значений. После F5 остаются тот же слот и страницы; новый выбор слота начинает новый поиск.
- При скрытии «Показать ещё» после последней порции клавиатурный фокус передаётся первой вновь открытой карточке и доводится до видимой области. Счётчики показывают фактически отрисованное количество и не становятся D1-контентом.
- Расширены уже имеющиеся Node и реальный Chromium сценарии с source-backed набором оружия воина, проверкой идентичности DOM, полной догрузкой, F5 и фильтрами. Новых тестовых точек входа нет; игровой клиент, Worker и production D1 не изменялись.

## 0.908.0 — 2026.11.19.908 · Экипировка: подсказки действий и полный счётчик душ

- Исправлен ошибочный контекст вызова общего контроллера подсказок. Три вкладки экипировки теперь отображают RU/EN справку на hover и при клавиатурном фокусе, поддерживают Escape и ARIA. Уже существующие D1-ключи редактора, CAS/Undo обновляют текст без пересоздания текущего предмета. Меню ПКМ не закрывается от прокрутки несвязанного блока, но закрывается при перемещении слота.
- Счётчик совместимых душ остаётся видимым после последней страницы («Душ: N из N» / «N of N Souls»); скрывается только кнопка «Показать ещё» и редакторский карандаш этой кнопки. Ранее исчезала вся панель прогресса. Сохранено постраничное добавление и перенос фокуса.
- Нулевая вместимость душ не вызывает принудительного перехода со вкладки управления: уже существующее сообщение про 0 слотов остаётся доступным. Без изменений игровых формул, Cloudflare Worker и production D1.
- Расширены существующие Node/Chromium сценарии для реального интерфейса, EN D1-CAS/Undo, RU/EN, 186 душ, фокуса и идентичности DOM-узлов.

## 0.907.0 — 2026.11.19.907 · Общая защита числовых полей и поиска от автозаполнения

- Один проверяемый Yandex guard защищает все неавторизационные поля типа search/number: случайная или программная подмена значения, а также синтетические input/change не вызывают сохранения неверной характеристики, уровня или поиска. При фокусе и безопасных пользовательских жестах сохраняются реальные значения.
- Ввод клавиатурой, мышью, тачем, вставка, удаление, IME/диктовка и undo/redo используют одинаковую проверку доверенного события. Поля логина/пароля не затронуты; блокировка браузерного всплывающего менеджера паролей не гарантируется.
- Удалены две разошедшиеся реализации Yandex-наблюдателей. Штатные обновления через +/−, пересчёты характеристик, числовой owner-редактор и замер Энциклопедии теперь явно синхронизируют значения без разблокировки посторонних событий. Node/Chromium регрессии дополнены; новых тестовых entrypoints нет. D1, Worker и формулы не менялись.
- Browser acceptance and deployed Pages state must be verified separately.

## 0.906.0 — 2026.11.19.906 · Безопасный поиск и D1-подпись прогресса душ

- В Яндекс Браузере синтетические keydown/pointerdown больше не снимают защиту поискового поля. Доверенные события вставки, перетаскивания, диктовки, удаления и Undo распознаются при фокусе; автозаполнение логином по-прежнему отбрасывается.
- В списке совместимых душ текст «Душ» / «Souls» получил стабильный RU/EN D1-ключ и компактный карандаш владельца. Числа текущей страницы и общего результата существуют независимо от редактируемой подписи; дозагрузка не пересоздаёт её.
- Расширены существующие Node/Chromium тесты синтетических событий, RU/EN, чисел, жизни DOM при пагинации и доступа владельца. Игровые формулы, каталог, Worker и production D1 не менялись.
- Browser acceptance and deployed Pages state must be verified separately.

## 0.905.0 — 2026.11.18.905 · Энциклопедия: строгий D1, редактируемые результаты и чистка наследия

- Общий загрузчик Энциклопедии больше не может подменить неисправный D1-снимок архивным на публичном сайте: даже если вызывающий код не указывает `strict:true`, ошибка D1 остаётся ошибкой, а `preferLocal` запрещён. Локальные игровые fixtures остаются только для изолированных тестов Node/localhost.
- Удалены устаревший HTML-баннер архивного режима и его невостребованная отрисовка; убран второй проход нормализации старых числовых веток мастерства. Сохранена одна корректная миграция.
- **10 новых RU/EN D1-подписей** в существующем редакторе Энциклопедии: возврат, «Показано / из / записей», «Показать ещё», отсутствие результатов, подсказка выбора записи, районы Астира, государства и другие локации.
- Количество показанных и всех результатов, размер следующей порции и остаток остаются отдельными, неизменяемыми текстовыми узлами. CAS, Undo и смена подписи не заменяют список, фильтр или числа.
- Расширены существующие Node/Chromium-тесты для отказа от архивной подмены на публичном хосте, локальных fixtures, D1-редактирования, конфликта 409, Undo, «Показать ещё» и локаций. Игровые формулы, Worker и production D1 не изменены.

## 0.904.0 — 2026.11.18.904 · Доступные RU/EN-подписи фильтров Энциклопедии

- Четыре семейства фильтров Энциклопедии используют общую модель подписей и D1-CAS: 14 вариантов вида экипировки, 2 выбора совместимости героя, 7 стихий, 7 категорий предметов эффектов и пять доступных названий селекторов (всего 35 новых редактируемых подписей); существующий редактор категорий навыков не продублирован.
- В режиме владельца эти опции редактируются в одном сворачиваемом разделе на самой странице. В обычном режиме нет панелей или карандашей редактора. Длинный список прокручивается внутри, не раздувая страницу.
- Для каждой опции сохраняются стабильный внутренний ID фильтра и RU/EN-текст отдельно; D1-подписи не меняют сортировку, выбор экипировки, условия совместимости или предметы. Сохранение, Undo, конфликты CAS и смена языка используют текущие механизмы без отдельной таблицы или новой панели.
- Дополнены существующие Node/Chromium регрессии на исходные ID, RU/EN D1-запись, фильтрацию, выбор категории и условные элементы. Игровые формулы, Worker и production D1 не изменены.

## 0.903.0 — 2026.11.18.903 · Обновление без ложного режима редактора

- Разделены причины блокировки релиза: активный режим владельца, незавершённая D1-запись, D1-подключение, открытые формы и предупреждения аккаунта. Неактивный администратор с сохранённой авторизацией больше не получает текст «выйди из редактора»; сохранение имеет собственный RU/EN-текст и стабильный D1-ключ.

- Расширены существующие Node и Chromium-тесты: гость без единого входа в редактор, завершённый режим с сохранённым токеном, ожидающие D1-CAS записи, ручное и автоматическое обновление и безопасный переход с cache-bust URL.
- Worker, игровые каталоги, расчёты и production D1 не изменены; клиент игры не использовался.

## 0.902.0 — 2026.11.18.902 · Понятный выбор экипировки и доступность нулевых слотов

- В свойствах вместо «Выбор» — «Выбрать другую вещь» (EN: «Choose another item»), как в меню ПКМ. Все исходные подписи действий теперь из одного набора; прежние D1 RU/EN-ключи редактора сохранены.

- Расширены Chromium-регрессии: RU/EN, телефон, компоновка, 0 слотов, редактирование CAS/Undo. Формулы, игровые данные, Worker и production D1 не менялись.
