# Pandora Saga Build Studio — CHANGELOG

## 0.967.0 — 2026.11.27.967 · Союзные усиления проверяют классы, уровень и требования текущего OS перед показом и применением

- Союзные усиления проверяют классы, уровень и требования текущего OS перед показом и применением.
- Шесть независимых подсказок Книги героя и действующие Remaked-эффекты отклоняют неподтверждённое изменение исходных классов, требований, базового уровня и вида корневого умения.
- Уже подтверждённые параметры FV1 остаются динамическими; нормальные 571 умение и 28 классов сохраняют прежние величины. Базовые формулы Remaked остаются model/unverified.
- У остальных союзных Remaked-корней источник должен оставаться доступным и корректно описывать обучение; получающий герой не обязан иметь профессию применяющего союзника.
- Node регрессии: 6 основных корней × изменения доступа, применение к получателю, 28 классов × 55 уровней. Полный Chromium / Pages / Worker D1 read-only без изменения каталога.
- Пользовательские билды, Cloudflare Worker, D1, CAS и данные игры не изменены.

## 0.966.0 — 2026.11.27.966 · Шесть союзных усилений читают одни OS-коэффициенты для подсказок и применения

- Шесть союзных усилений читают одни OS-коэффициенты для подсказок и применения.
- Боевой клич, Массовая сосредоточенность, Помощь ветра, Благословение ветра, Божественное благословение и Благословенный покой используют единый источник FV1[3] текущего OS.
- Модуль Remaked применяет тот же коэффициент для выбранных эффектов точности, магической защиты и восстановления ОМ; шесть независимых подсказок Книги героя согласованы с применяемыми бонусами.
- Модель отклоняет новые каналы FV, неизвестные эффекты и направления, оставляя клиентские формулы unverified.
- Прямые D1/Worker/сохранения не менялись; обязательный Node + Chromium + Pages/read-only readiness.

## 0.965.0 — 2026.11.27.965 · Воодушевление и Вольный ветер читают подтверждённые коэффициенты FV1 OS

- Воодушевление и Вольный ветер читают подтверждённые коэффициенты FV1 OS.
- Воодушевление: подтверждённый FV1[3] OS заменяет 50 без проверки новых скрытых каналов; Remaked-рецепт перевода в индекс времени остаётся моделью.
- Вольный ветер: FV1[3] OS заменяет 200 при прежней обязательной отмене на смене карты.
- Неподдерживаемые FV-поля/направления блокируют модель; пользовательские билды, Worker, D1 и CAS не затронуты.
- Обязательная приёмка Node/Chromium/Pages/read-only readiness.

## 0.964.0 — 2026.11.27.964 · Ободрение и три песнопения читают коэффициенты FV1 из OS вместо старых чисел Remaked

- Ободрение и три песнопения читают коэффициенты FV1 из OS вместо старых чисел Remaked.
- Все три песнопения теперь читают числовые коэффициенты из текущих подтверждённых FV1 OS; проверяются исходные дочерние цепочки, безопасные границы и нулевой FV2.
- Общая прибавка Ободрения используется только при равенстве всех трёх TARGET-векторов STR/AGI/INT; неизвестная зависимость не предполагается.
- Модели округления Remaked остаются `verified:false`; эффекты не активируются автоматически, сохраняемые билды и D1/CAS не меняются.
- Полные Node/Chromium и Pages/Worker/D1 read-only обязательны перед приёмкой.

## 0.963.0 — 2026.11.27.963 · Три эффекта Чар усиления читают FV1 OS; обновлены диагностические предупреждения официального каталога

- Три эффекта Чар усиления читают FV1 OS; обновлены диагностические предупреждения официального каталога.
- ENCHANTER, `320011001`: `EP_AURADAMAGE_SCALE`, `EP_AURADAMAGE_CONST`, `EP_ELEMENT_DAMAGE_SCALE` вычисляются из трёх подписанных `FV1` OS. Исходные Remaked-округления и прежние числа сохранены, новая непроверенная зависимость блокирует весь набор.
- Историческая копия `data/os/meta.json.warnings` приведена к 13 предупреждениям публичного OS API на 27.11.2026; никакие числовые параметры предметов/навыков, D1 или пользовательские билды не затронуты.
- Регрессии: числовые модели, групповая целостность трёх эффектов, защита от неожиданного `FV2`/класса/направления, каталог перед публикацией. Серверное применение пока остаётся моделью.

## 0.962.0 — 2026.11.27.962 · Знаки жреца используют живые FV1 OS; устранено ложное отличие meta.curated в проверке 17 источников

- Знаки жреца используют живые FV1 OS; устранено ложное отличие meta.curated в проверке 17 источников.
- Gratia `320007001`, Lapis `320008001`, Group Barrier `320003001` и Holy Weapon `330051001`: этапы округления Remaked теперь используют FV1 актуального OS skill-каталога без дублирующих констант.
- Подсказки жреца и применяемые выбранные баффы используют один и тот же источник. Новые зависимость от уровня, несоответствие FV2/направления, некорректные числа или требования блокируют расчёт, не изменяя игровые данные.
- Корректно распознаётся локальный `data/os/meta.json.curated=true` в отдельном 17-наборном read-only официальном аудите; все числовые OS-поля остаются строго сравниваемыми.
- Нулевые/изменённые коэффициенты смоделированы тестами без правок production D1, сохранённых билдов, CAS или Worker. Серверный порядок стадий не объявлен доказанным.

## 0.961.0 — 2026.11.26.961 · Отметили модельность точности и уклонения Remaked; обновили восстановления ОЗ/ОМ от союзников по FV1 OS; проверка API в релизном CI

- Отметили модельность точности и уклонения Remaked; обновили восстановления ОЗ/ОМ от союзников по FV1 OS; проверка API в релизном CI
- `alliedHpPulsePreview` и `alliedNaturalRecoveryPreview` читают исходные FV1 из OS каталога, не из дублированных коэффициентов. Текущие числа сохранены, корректные будущие коэффициенты проигрываются с исходными стадиями Remaked; новые неизвестные зависимости отклоняются.
- Регрессии: сравнение союзных HP/MP пульсов с периодическими моделями жреца, исходные значения, изменённые FV1, нарушения направления/FV2/триггера и правил доступа.
- В Книге героя «Точность» и «Уклонение» показывают маркер «модель» / «model» и RU/EN описание источника; рассчитанные числа и официальные параметры не изменены.
- Актуальный OS API `tables.levelCap:50`; Build Studio по-прежнему планирует до 55. Сверка 17 игровых JSON в релизном CI — только чтение; правки D1 запрещены.
- Node-регрессии 28 профессий × уровни 1–55, доступные подписи, статус результата и безопасное разделение оригинального OS API от Remaked.

## 0.960.0 — 2026.11.26.960 · Модели лечения читают актуальные коэффициенты умений OS; подсказки силы заклинаний показывают «модель»
