## 0.948.0 — 2026.11.25.948 · #390: RU/EN D1/CAS-подписи редких состояний, доступность Пути героя и общие тексты Происхождения; числовые игровые данные защищены

- Цикл isolated staging 0.947.0: реальный экспорт → импорт → независимая SHA-256 сверка 2 732 строк → зашифрованная копия → точечный откат. Это проверка ПРЕДЫДУЩЕГО снимка, не миграция нынешней версии 0.948.0 в production.
- Цикл isolated staging **0.948.0** на реальной удалённой Cloudflare D1 тоже прошёл полностью: защищённый бэкап до → импорт **2 734** авторских RU/EN строк → отдельная сверка SHA-256 `5637e5c111eb452800609eb44f808f2f9d465277252595ad8e2c125f79cb6c8d` → зашифрованный бэкап после → точечный откат 0 строк/маркеров. Production-база не затрагивалась.
- В настоящем онлайн-запуске добавлена строго закреплённая read-only D1-загрузка снимка `0.948.0-5637e5c111eb4528` перед применением owner CAS. - Реальный Node + Chromium, отдельная миграция текущего defaults в production и read-only аудит опубликованных Pages/Worker/D1 являются релизными gate, а не заранее заявленными результатами.
