# Pandora Saga Build Studio — CHANGELOG

## 0.960.0 — 2026.11.26.960 · Указали модельный статус точности и уклонения Remaked; добавили проверку актуального OS API в релизные отчёты

- Указали модельный статус точности и уклонения Remaked; добавили проверку актуального OS API в релизные отчёты.
- В Книге героя «Точность» и «Уклонение» показывают видимый маркер «модель» / «model» и RU/EN описание источника; рассчитанные числа и официальные значения параметров не изменены.
- Актуальный OS API `tables.levelCap:50`; Build Studio по-прежнему планирует до 55. Сверка 17 игровых JSON в релизном CI — только чтение; правки D1 запрещены.
- Новые Node-регрессии 28 профессий × уровни 1–55, доступные подписи, статус результата и безопасное разделение оригинального OS API от Remaked.
