# Pandora Saga Build Studio — CHANGELOG

## 0.881.0 — 2026.11.18.881 · Нативная модальная блокировка D1 и безопасное восстановление фокуса

- Экран обязательного D1-подключения и безопасного обновления получает нативную `inert`-блокировку фона: недоступны навигация с клавиатуры, фокус и элементы для экранного диктора за диалогом.
- Сохраняется исходное состояние элементов, уже помеченных `inert`; новые добавленные элементы блокируются до восстановления, а фокус возвращается только после полного скрытия экрана.
- Устранён промежуток при анимации закрытия и загрузке английского перевода, когда обработчик событий раньше времени пропускал действия за видимым экраном.
- Node и Chromium проверяют начальный отказ D1, реконнект, потерю сети, динамические элементы и сохранение owner-черновиков без записи в production D1.


## 0.880.0 — 2026.11.18.880 · Вариант B: защита первого запуска D1 при отказе сохранения героя или библиотеки

- Подтверждённый онлайн-каталог больше не разблокирует редактор, пока первая запись текущего героя **и** библиотеки билдов в localStorage не завершилась успешно.
- Если браузер отказал в записи, состояние остаётся в памяти за экраном защиты; «Повторить сохранение» не перезагружает каталог и не отправляет черновик в D1.
- Сообщения о нехватке хранилища охватывают героя и библиотеку; Chromium проверяет независимые отказы обеих записей и безопасное восстановление.
- Дополнительно предотвращена незаметная перестановка записей сохранённой библиотеки: проверка готовности сохраняет исходный порядок, если сами билды не изменились.
- Добавлены проверки исходного кода и браузерная приёмка новых сценариев; итоговые результаты Node/Chromium фиксируются в PR.


## 0.879.0 — 2026.11.18.879 · Глубокий аудит online-only D1 и восстановление без потери черновиков

- Черновик, старые очки навыков и изменения экипировки не записываются в браузер до финального согласования D1-каталога и редакторских RU/EN-изменений; при неуспешной загрузке первоначальный герой возвращается в память.
- Устранена потеря вложенных очков: при миграции старых числовых ключей веток и мастерства ненулевое вложение больше не затирается нулевым современным значением по умолчанию.
- Запрет конкурирующих ручных и автоматических запусков, защита клавиатуры и форм за блокирующим экраном, и проверка каталога при возврате фокуса и каждые 45 секунд.
- Обновление D1 сохраняет приоритет над последующими событиями offline. Несохранённый текст авторизованного владельца доступен для ручного копирования и явного подтверждения перезагрузки без непреднамеренной D1-записи по blur.
- Облачная библиотека аккаунта запускается только после подтверждения D1; полноценные Node/Chromium регрессии охватывают отказ D1, сохранение текущего героя, восстановление и незавершённое редактирование.
- Устранён прямой обход безопасной перезагрузки после публикации нового каталога через админку: открытый билд не пересчитывается незаметно по новым данным.


## 0.878.0 — 2026.11.18.878 · Обязательный D1-онлайн и безопасное восстановление без архива

- Публичный экран запуска больше не предлагает архивную копию; перед открытием редактора обязательны согласованный D1-каталог и авторские RU/EN-изменения.
- Монитор соединения проверяет опубликованный снимок и авторские тексты по D1 на чтение; обрыв блокирует устаревшие расчёты, сохраняя текущего героя и локальную библиотеку.
- При восстановлении той же версии работа продолжается; при новом D1-снимке нужна явная защищённая перезагрузка через уже существующий `pandora:before-update`. Облачные изменения не выдаются за подтверждённые до синхронизации.
- Локальные игровые файлы доступны исключительно на localhost/127.0.0.1 для разработки и Chromium CI. Добавлены Node и Chromium проверки офлайн-запуска, реконнекта и сохранности черновика.


## 0.877.0 — 2026.11.17.877 · Понятные ошибки аккаунта RU/EN без серверных подробностей

- 13 подтверждённых ответов API аккаунта переведены на RU/EN: неверный пароль, резервный код, занятый логин, лимит попыток и другие действия.
- Неизвестные ответы, сообщения БД/Worker и обрывы сети больше не показывают технические подробности. Статус HTTP сохраняется внутри обработки, чтобы не нарушать отзыв сессий.
- После смены языка уже показанная ошибка корректно переводится, но пароли/коды и ответы сервера не становятся редактируемыми D1-текстами.
- Node и Chromium проверяют 401, 503, offline, безопасность гостя и сохранение смысла RU/EN.


## 0.876.0 — 2026.11.17.876 · Облачная библиотека: RU/EN D1-подписи и надёжное переключение статусов

- 21 фиксированное сообщение жизненного цикла облачной библиотеки получило стабильные RU/EN-ключи в `guideedit.book.ui.label.*`.
- Владелец редактирует действующую подпись на месте; карандаш появляется только с подтверждённой авторизацией, меняется вместе со статусом и не остаётся у старого ключа.
- RU/EN сохраняются независимо; CAS и отмена используют общий редактор. Динамические количества, ответы сервера и названия билдов не становятся редактируемыми текстами D1.
- Добавлены Node и Chromium проверки с живой сменой статуса; production D1 не меняется ради текстов по умолчанию.
